## 当前引用规则

- UART3 接线设计基线仅引用 _4.jpg 中的命名：IO32/TXD、IO33/RXD。连接前必须复核模块丝印和最新厂商资料。
- 资料中出现的典型电流、供电和能力描述都不是本项目的实测结果；项目电气参数以未来实验记录为准。
- 需要引用某一页时，写出完整文件名、资料版本（如可识别）和该页可见内容，避免只凭记忆转述。
