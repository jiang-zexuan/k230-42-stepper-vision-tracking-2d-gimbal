# 测试计划

## 测试层次

| 层次 | 对象 | 目标 |
| --- | --- | --- |
| 单元测试 | CRC、帧解析、限位和运动规划 | 用构造输入验证边界行为。 |
| 板级测试 | GPIO、UART、DMA、定时器 | 验证 F407 引脚与外设配置。 |
| 联调测试 | K230 与 F407 | 验证正常帧、断帧、错帧和超时保护。 |
| 系统测试 | 双轴云台 | 验证跟踪、限位、锁定与故障动作。 |
| 稳定性测试 | 完整系统 | 验证两小时持续运行。 |

每项测试应使用 test-report-template.md，原始证据放入 evidence/，并更新追踪矩阵。
