# P06：单轴运动控制器复盘

- 日期：2026-08-22
- 阶段状态：已完成软件测试、ARM 工程编译和板上实测。
- 当前轴：已确认 X42S 安装在水平轴。

## 这一步做了什么

已把当前二维云台的水平线束约束转成软件规则：人工回中位置是 `0°`，水平轴只允许在 `-90°` 到 `+90°` 之间运动。基于 X42S 当前 `3200 脉冲/圈` 的 16 细分设置，软件边界为 `-800` 到 `+800` 脉冲。

已新增与 HAL 无关的 `motion_limits` 模块，并在 KEY2 的 90° 固定移动入口调用它。未人工回零、目标越过边界或限位配置非法时，只输出拒绝日志，不启动 STEP。

随后已接入 X42S TTL 只读反馈：读取系统状态参数，解析母线电压、相电流、实时转速、实时位置、位置误差、编码器/校准状态、到位、使能和保护标志；运动期间每 100 ms 采样一次，停止后输出最终反馈。

## 为什么要学

电机能转不等于云台能安全转。没有机械限位开关时，程序必须在发脉冲前检查“这次运动完成后会不会超出允许范围”。把检查单独做成纯逻辑模块，可以先用测试验证边界，再接到真实电机，减少线束被扭伤的风险。

## 状态与规则

```text
位置无效 -- KEY2 --> 拒绝，提示先 KEY_UP 人工回零
0 -- 逆时针(+800 脉冲) --> +90°，允许
0 -- 顺时针(-800 脉冲) --> -90°，允许
+90° -- 继续逆时针 --> 拒绝
-90° -- 继续顺时针 --> 拒绝
边界 -- 反向回到内部 --> 允许
```

这里的角度是软件理论坐标，不是编码器测得的绝对角度。掉电、堵转、手动转动或丢步后，位置必须重新人工回零。

## 代码动作 -> 工程意图

| 代码动作 | 工程意图 | 大白话描述给 AI |
| --- | --- | --- |
| `MotionLimits_HorizontalDefault()` | 集中定义当前水平轴边界 | “按当前 16 细分，把水平 ±90° 换算成 ±800 脉冲，集中保存边界。” |
| `MotionLimits_CheckRelativeMove()` | 在发脉冲前预测目标位置 | “先用当前位置加本次增量，目标超界就拒绝，不能只检查当前点。” |
| KEY2 调用限位检查 | 把安全检查放在运动启动之前 | “只有检查通过才调用启动 800 脉冲轨迹的代码。” |
| `RelativePositionTracker_IsValid()` | 防止未知位置参与判断 | “没人工回零时，不要相信当前位置，也不要让电机移动。” |
| `HAL_UART_Transmit()` + `HAL_UART_Receive()` | 读取 X42S 固定长度状态回包 | “向电机发送只读查询，收到完整回包后再解析，不在脉冲中断里阻塞等待。” |

## 关键库函数卡片

本课新模块本身不直接调用 HAL，这是刻意的：边界算法可以在 PC 上测试。接入它的硬件入口仍使用 P05 已学过的 HAL 函数：

| 函数 | 参数与返回值 | 本项目用途 | 常见误区和底层理解 |
| --- | --- | --- | --- |
| `HAL_GPIO_ReadPin(GPIOx, GPIO_Pin)` | 端口、引脚；返回 `GPIO_PIN_SET/RESET` | 读取 KEY2 和 KEY_UP | 低有效按键不能把 `RESET` 误解为未按下；底层读取 GPIO 输入数据寄存器。 |
| `HAL_GPIO_WritePin(GPIOx, GPIO_Pin, PinState)` | 端口、引脚、电平；返回 `void` | 输出 DIR、EN | 它只改变电平，不代表电机已经走到目标；底层写 GPIO 的置位/复位寄存器。 |
| `HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1)` | 定时器句柄、通道；返回 `HAL_StatusTypeDef` | 限位通过后输出 STEP | 不检查返回值会把定时器启动失败误判成运动成功；底层开启定时器通道和计数。 |
| `HAL_TIM_PWM_Stop(&htim4, TIM_CHANNEL_1)` | 定时器句柄、通道；返回状态 | 到脉冲数或异常时停止 STEP | 停 PWM 和失能 EN 是两件事，当前代码两者都做。 |
| `HAL_UART_Transmit()` | UART 句柄、缓冲区、长度、超时；返回状态 | 输出“未回零/越界”原因 | 这是阻塞发送，只放在主循环日志路径，不放进定时器中断。 |

## 板上实测结果

- 已按 `KEY_UP` 建立人工零点；未回零时运动请求被拒绝。
- 从零点向两侧运行各 800 脉冲，理论位置分别到 `+90°`、`-90°`；运动方向与软件定义一致。
- 到达 `+90°` 或 `-90°` 后继续向外按键，输出 `MOTOR profile move rejected: horizontal_limit`，电机未继续运动。
- 在两侧边界切换方向后可以返回内部范围。
- 运动期间 X42S 反馈状态为 `enabled=yes`、`stall=clear`、`protect=clear`；采样位置误差最大约 `0.68°`。
- 停止后反馈为 `speed=0RPM`、`enabled=no`、`reached=yes`、`error=0.00deg`；`home=0x03` 表示编码器正常且校准表就绪。

## 仍待核验的边界

- 水平 `±90°` 是当前装配的线束保护设计值，完整机械行程和边界余量仍待核验。
- 俯仰轴不因“暂时不受线束影响”而视为无限旋转，数值范围待核验。
- 当前理论坐标仍依赖人工回中；断电、堵转、手动转动或位置可信度丢失后必须重新回中。
