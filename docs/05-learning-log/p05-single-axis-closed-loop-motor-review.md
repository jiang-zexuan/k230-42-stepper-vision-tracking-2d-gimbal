## 这一步做了什么

已将 F407 的 TIM4 PWM、GPIO 和板载按键组合成单轴电机验收台，控制张大头 ZDT X42S 第二代闭环步进电机 A 款（脉冲 + 串口 TTL）完成启停、方向、固定角度运动、加减速和理论位置记录。

## 接线与资料依据

依据《探索者 V3 硬件参考手册_V1.0》`2.1.2 引出 IO 口`，已使用：

| X42S | 探索者 V3 | 用途 |
| --- | --- | --- |
| Gnd | P9-43 或 P9-44 GND | 逻辑共地 |
| Stp | P9-4 / PB6 / TIM4_CH1 | STEP 脉冲 |
| Dir | P9-3 / PB7 | 方向电平 |
| En | P9-8 / PG15 | 使能电平 |
| Com | 不接 | 当前按普通 MCU 脉冲控制接法 |

电机电源与 F407 逻辑电源分开；已使用可调电源 `12.0 V`、初始限流 `1.0 A`，并与 F407 共地。依据 X42S 用户手册“注意事项（必读）”“1.5 产品参数”“2.1.1 STM32 脉冲控制接线”，X42S 常规版供电范围为 `10–29 V`，脉冲输入支持 `3.3–24 V`；当前电机菜单已实测为 `P_Pul=PUL_ENA`、`En=H`。

## 已实测现象

| 功能 | 实测结果 |
| --- | --- |
| 上电状态 | 不自动转动，EN 保持失能 |
| KEY0 | 启动/停止连续 STEP 输出；`500 Hz` 低速连续运行通过 |
| KEY1 | 只在停止状态换向；运行中换向被拒绝 |
| 方向 | 从输出轴正面观察，`DIR=Low` 为逆时针，`DIR=High` 为顺时针 |
| KEY2 | 发送 800 个 STEP 脉冲，完成约 90 度运动后自动停止 |
| 加减速 | 100 -> 200 -> 300 -> 400 -> 500 Hz，再对称减速；运动无突然启停 |
| KEY_UP | 人工对准机械参考姿态后建立理论零点 |
| 连续控制后位置 | 软件理论位置主动标记为无效，要求重新人工回零 |
| 短时持续运行 | 约 30 秒运行检查通过；未见异常运动、报警或明显温升，温度数值未测 |

X42S 当前 16 细分设置为 `3200 脉冲/圈`，因此 `90 度 = 800 脉冲`；这是指令角度换算，不是编码器反馈的绝对角度。

## 学到了什么

1. STEP 脉冲频率决定速度，脉冲总数决定理论位移，DIR 电平决定方向，EN 决定驱动使能。
2. `Low/High` 只是 GPIO 电平，顺时针/逆时针必须固定观察视角后实测确认。
3. 运行中直接改变 DIR 会带来机械冲击，因此状态机只允许在 STOPPED 状态换向。
4. 从静止直接跳到高频可能丢步；分段加减速让转子有时间跟随脉冲。
5. 软件累计位置是相对理论坐标，不是编码器真实位置；掉电、手拧、堵转或丢步后必须重新人工回零。
6. 中断只负责计数和快速停止硬件，串口格式化和日志发送放在主循环，避免在中断里阻塞。

## 状态机

```text
STOPPED
  | KEY0
  v
RUNNING <---- KEY0 ---- STOPPED

STOPPED -- KEY2 --> ACCELERATING --> CRUISING --> DECELERATING --> STOPPED
STOPPED -- KEY1 --> 只改变 DIR
RUNNING -- KEY1 --> 拒绝换向
KEY_UP（停止） --> 理论位置 = 0
```

## 代码动作 -> 工程意图

| 代码动作 | 工程意图 | 大白话描述给 AI |
| --- | --- | --- |
| `HAL_TIM_PWM_Start/Stop()` | 控制 STEP 是否持续输出 | “用 TIM4 PWM 作为 STEP，启停时必须同时控制 EN。” |
| `MotorPulseLab_ToggleDirection()` | 防止运行中换向 | “只允许停机时切换方向，运行中请求直接拒绝并记录。” |
| `MotorPulseLab_OnPulsePeriod()` | 每个定时器周期消耗一个目标脉冲 | “固定运动严格发送 800 个周期，达到目标后立即停止。” |
| 分段预设分频值 | 实现梯形加减速 | “按阶段从 100 Hz 平滑升到 500 Hz，再降回 100 Hz，总脉冲不能改变。” |
| `RelativePositionTracker_SetManualZero()` | 建立人工确认的理论零点 | “只有人工确认当前位置后才允许累计相对角度。” |
| `RelativePositionTracker_Invalidate()` | 防止不可信位置继续传播 | “连续运动、取消、掉电或异常后把位置标记为无效，要求重新回零。” |
