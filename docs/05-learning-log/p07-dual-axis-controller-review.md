# P07：双轴云台基础控制器复盘

- 日期：2026-08-22
- 阶段状态：双轴方向、人工归中、接管、同步运动和软件限位已板上实测通过。
- 当前硬件：两台张大头 X42S；水平轴使用 TIM4，俯仰轴使用 TIM3。

## 这一步做了什么

已为俯仰轴增加独立 STEP/DIR/ENA 控制，并确认 PC9、PC8、PC7 与 X42S 的接线和电机主电源条件。复位后两个轴失能，可以手动调整；手动把两个轴归中后按 KEY_UP，软件记录零点并拉高 EN，使两台电机进入接管态。

已实测并修正俯仰方向：DIR 低电平对应向上，DIR 高电平对应向下。以 KEY_UP 位置为 0，俯仰软件范围为 -45° 到 +45°；当前 16 细分下边界为 ±400 脉冲。水平轴继续使用 -90° 到 +90°，边界为 ±800 脉冲。

已加入 DUAL_TEST 和 DUAL_TEST_NEG。两轴在一次命令中先统一检查零点、忙状态和各自限位，检查通过后同时输出 100 个脉冲；任一轴不满足条件，两个轴都拒绝启动。

## 为什么要学

单轴能转不等于云台能安全协同运动。双轴控制需要同时维护两个坐标、两个定时器和两个限位，任何一个轴越界都不能让另一个轴单独执行。先建立可靠执行机构，再接入 K230，可以把视觉误差、串口协议和电机安全问题分开学习和验证。

## 代码动作 -> 工程意图

| 代码动作 | 工程意图 | 大白话描述给 AI |
| --- | --- | --- |
| `KEY_UP` 设置两个软件零点并拉高 EN | 从人工机械中心开始接管 | “复位后允许手动摆正，按键确认中心后锁住两个轴。” |
| `HAL_TIM_PWM_Start(&htim3/htim4, ...)` | 启动俯仰或水平 STEP 脉冲 | “通过两个独立定时器分别控制两个电机。” |
| 双轴命令先调用限位检查 | 防止半执行 | “两个轴一起检查，只要一个目标越界，两个都不要动。” |
| TIM3 更新中断统计联动脉冲 | 用同一控制时基结束同步测试 | “两个轴同时开始，公共计数到目标后同时停止。” |
| `PITCH_STOP` 中途停止后使坐标失效 | 防止部分脉冲被误当成完整位移 | “运动被打断后必须重新归中，不能继续相信旧坐标。” |

## 关键 HAL 函数卡片

| 函数 | 本项目用途 |
| --- | --- |
| `HAL_TIM_PWM_Start()` | 在 PC9 或 PB6 输出 STEP 脉冲。 |
| `HAL_TIM_Base_Start_IT()` | 开启定时器更新中断，用于脉冲计数和停止。 |
| `HAL_TIM_PWM_Stop()` | 停止 STEP 输出；与 EN 失能是两个不同动作。 |
| `HAL_GPIO_WritePin()` | 设置两个轴的 DIR 和 EN 电平。 |
| `HAL_GPIO_ReadPin()` | 读取 KEY_UP，确认人工回中和接管请求。 |

## 板上实测结果

- 复位后两台电机均可手动转动；按 KEY_UP 后两台均锁定。
- `PITCH_UP` 实测向上，`PITCH_DOWN` 实测向下。
- 俯仰正、负方向各到达 45° 后，继续外向命令被拒绝。
- `DUAL_TEST` 连续 4 次通过，第 5 次因俯仰正向限位拒绝。
- `DUAL_TEST_NEG` 反向联动和负方向限位已通过。
- 心跳日志已调整为每 5 秒一次；10 ms 按键扫描和 100 ms 状态任务仍保持运行。

## 当前限制

- 坐标是脉冲累计理论坐标，不是上电即可恢复的绝对坐标。
- 复位、手动转动、堵转或中途停止后，必须重新人工归中并按 KEY_UP。
- 尚未把 K230 视觉目标接入双轴运动；下一阶段进入 P08 正式通信链路。
