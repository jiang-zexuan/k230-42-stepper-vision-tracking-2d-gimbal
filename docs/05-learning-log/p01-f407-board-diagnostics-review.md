## 本项目解决的问题

P01 的目标不是实现复杂功能，而是建立后续所有 F407 工作依赖的最小闭环：能够生成工程、下载调试、控制一个输出、读取一个输入，并把关键状态送到 PC 串口。

## 代码到意图

| 代码或配置 | 它实现的意图 |
| --- | --- |
| CubeMX：SYS Debug = Serial Wire | 允许 ST-Link 通过 SWD 控制和调试芯片。 |
| PF9 输出、高电平初始 | DS0 为低有效，初始化为高电平可令其熄灭。 |
| PE4 输入、内部上拉 | 未按 KEY0 时稳定读取高电平；按下后读取低电平。 |
| `HAL_GPIO_ReadPin()` | 获取按键此刻的电平状态。 |

| `HAL_Delay(20)` 后复查 | 过滤机械按键在按下瞬间的抖动。 |

## 已理解的关键知识

1. HAL 没有改变外设开发的本质：仍是开时钟、配置 GPIO/外设、读写数据；它把寄存器细节封装为句柄和函数。
2. `main()` 的基本顺序是 `HAL_Init()`、时钟配置、`MX_GPIO_Init()`、`MX_USART1_UART_Init()`、用户应用逻辑。
3. GPIO 的输入和输出是两条不同方向的链路：按键电平进入 CPU，CPU 输出电平改变 LED。
4. USART1 到 PC 的实测链路是 F407 USART1 -> PA9 -> CH340C -> USB -> COM8。
5. `HAL_Delay()` 适合当前简单消抖，但它会阻塞 CPU；周期任务应以时间差判断为基础。这是 P02 的入口。
6. C 变量的作用域决定其可见范围；`current_tick` 必须在 `while` 循环内定义并在循环内使用，枚举项和变量不能重复定义。
