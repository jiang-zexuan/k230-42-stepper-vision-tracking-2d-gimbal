# 验收准则

| 验收项 | 判定标准 | 当前状态 |
| --- | --- | --- |
| 位置方向 | 人工回中后，两轴累计方向与实物一致 | 待建测试 |
| 软件限位 | 水平不越过正负 180 度，俯仰不越过正负 45 度 | 待建测试 |
| 跟踪误差 | 目标稳定时，中心误差不超过画面宽高的 5% | 待建测试 |
| 视觉帧率 | 正常光照下检测和输出不低于 20 FPS | 待建测试 |
| 锁定 | 稳定居中 500 ms 后进入 LOCKED | 待建测试 |
| 失联保护 | K230 断线或目标丢失后 300 ms 内停止跟踪 | 待建测试 |
| 协议鲁棒性 | 错字节、断帧、CRC 错误不引发异常运动且可重新同步 | 待建测试 |
| 稳定性 | 连续运行 2 小时无死机、栈溢出或非预期复位 | 待建测试 |

验收通过的证据必须写入 docs/07-test/traceability-matrix.md，并链接原始日志、图片或视频。
