# 系统需求

以下为需求基线。实现前的设计方案必须遵守，实际性能仍需通过测试确认。

| ID | 需求 |
| --- | --- |
| REQ-001 | 系统应在人工回中后，将该位置作为两轴软件零点。 |
| REQ-002 | 水平轴位置估算不得超过 -180 到 +180 度，俯仰轴不得超过 -45 到 +45 度。 |
| REQ-003 | K230 应至少以 20 Hz 发送目标结果；无目标时也应发送状态帧。 |
| REQ-004 | F407 超过 300 ms 未收到有效帧时，应停止电机并进入目标丢失状态。 |
| REQ-005 | 非法长度、未知协议版本和 CRC 错误帧不得更新运动目标，只可计入错误统计。 |
| REQ-006 | 目标稳定居中 500 ms 后，系统应进入 LOCKED 状态。 |
| REQ-007 | 第一版不使用主动光学发射器；仅以屏幕、LED 或蜂鸣器表达锁定状态。 |
| REQ-008 | 应记录任务存活、通信错误和故障码，支持故障复现。 |
| REQ-009 | 连续运行两小时不应发生已知的死机、栈溢出或非预期复位。 |
