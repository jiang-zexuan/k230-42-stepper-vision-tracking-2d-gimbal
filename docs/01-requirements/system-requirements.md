# 系统需求

以下为需求基线。实现前的设计方案必须遵守，实际性能仍需通过测试确认。

| ID | 需求 |
| --- | --- |
| REQ-001 | 系统应在人工回中后，将该位置作为两轴软件零点。 |
| REQ-002 | 当前装配下，水平轴位置估算不得超过 -90 到 +90 度；俯仰轴必须使用已核验的机械范围，范围未确认前不得假设无限旋转。 |
| REQ-003 | K230 应至少以 20 Hz 发送目标结果；无目标时也应发送状态帧。 |
| REQ-004 | F407 超过 300 ms 未收到有效帧时，应停止电机并进入目标丢失状态。 |
| REQ-005 | 非法长度、未知协议版本和 CRC 错误帧不得更新运动目标，只可计入错误统计。 |
| REQ-006 | 目标稳定居中 500 ms 后，系统应进入 LOCKED 状态。 |
| REQ-007 | 命中状态应同时支持屏幕、音效和受控光学指示模块；PF10 仅在命中提示期间有效，音效结束、停止、故障或复位时必须关闭。 |
| REQ-008 | 应记录任务存活、通信错误和故障码，支持故障复现。 |
| REQ-009 | 连续运行两小时不应发生已知的死机、栈溢出或非预期复位。 |
| REQ-010 | F407 板级诊断应通过经资料核验并经实物确认的 SWD、状态 LED、按键和调试串口，提供可复现的下载、状态指示、按键事件和启动日志证据。 |
| REQ-011 | F407 应以协作式裸机周期任务执行 10 ms 按键扫描、100 ms 状态维护和 500 ms 心跳日志；按键消抖不得以阻塞式延时停止主循环。 |
| REQ-017 | 在人工回中和软件接管后，水平视觉控制应将画面 X 误差转换为带死区、比例和最大速度限制的 STEP 目标；无目标、通信超时或软件限位时必须停止水平 STEP。 |
