## 证据和状态说明

本表的 F407 引脚来自旧工程 `PanViewF407.ioc`、`Core/Inc/main.h` 和 `Core/Src/main.c`；“接线未变”来自 2026-09-02 的操作者确认。它可以作为新工程 CubeMX 配置基线，但不替代新工程的引脚复核、万用表检查和低风险上电验证。

状态含义：

- **设计基线**：允许用于创建新工程配置，尚未代表新工程实测。
- **用户确认沿用**：接线相对旧工程未变的当前输入。
- **待验证**：需要通过 CubeMX 配置检查、开发板资料或实机测量确认。

## 调试和复核清单

新工程 T00 首次生成后必须逐项确认：

1. CubeMX 的引脚标签、外设复用和 DMA Stream 与本表一致。
2. PA13/PA14 SWD 调试接口未被占用。
3. 两个定时器 PWM 输出没有被其他外设复用覆盖。
4. I2C1 共用设备地址不冲突，必要时通过总线扫描或读 ID 验证。
5. UART 逻辑电平、5V 供电和共地在接线前依据开发板和模块资料复核。
6. 新工程下载后先验证 LED/UART，再验证 TFT/触摸，最后才接入电机使能和 STEP 输出。
