# K230 与 F407 UART 接口

## 物理连接设计基线

| K230 12 Pin 接口 | F407 信号 | 方向 | 状态 |
| --- | --- | --- | --- |
| IO32 / UART3_TXD | F407 UART_RX | K230 到 F407 | 待验证 |
| IO33 / UART3_RXD | F407 UART_TX | F407 到 K230 | 待验证 |
| GND | GND | 双方共地 | 接线前核验 |

K230 引脚名称来自随模块附带的原始说明图，见 hardware/datasheets/yahboom-k230-standard/README.md。F407 使用哪一路 UART 及对应引脚尚未建立 CubeMX 工程，不能据此直接接线。

## 二进制帧设计

帧布局：SOF_AA55 | 协议版本 | 长度 | 帧序号 | 目标状态 | 类别 ID | 中心 X | 中心 Y | 宽 | 高 | 置信度 | CRC16_MODBUS。

多字节整数采用小端。长度字段的精确定义、状态枚举和最大长度在首个解析器实现前固定，并增加自动化测试向量。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| SOF | 2 字节 | 固定为 AA 55，用于重同步。 |
| version | u8 | 协议版本。 |
| length | u8 | 设计中为后续可扩展长度字段，语义待固定。 |
| sequence | u16 little-endian | 发送序号。 |
| target_status | u8 | 是否检测到可用目标。 |
| class_id | u8 | 模型类别编号。 |
| center_x, center_y | u16 little-endian | 目标中心像素坐标。 |
| width, height | u16 little-endian | 目标框像素尺寸。 |
| confidence | u8 | 置信度编码，缩放规则待固定。 |
| crc | u16 little-endian | CRC16/MODBUS，覆盖范围待解析器测试确定。 |

## 安全约束

- K230 至少 20 Hz 发送检测或无目标状态。
- F407 在 300 ms 没收到有效帧时停止电机并进入 LOST。
- CRC 错误、非法长度和未知版本只计错误，不能更新运动目标。
- 示例字节流与 CRC 只能作为设计测试向量，不得作为硬件实测证据。
