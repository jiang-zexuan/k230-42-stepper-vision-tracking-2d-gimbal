# ADR-0001：项目基线

## 状态

已采纳，硬件连接和性能参数待验证。

## 背景

项目需要一个能体现边缘视觉、实时控制、通信容错和工程化交付的学习载体。现有资源是 F407 探索者与 K230 标准版视觉模块。

## 决策

- K230 独立运行检测模型，F407 仅接收结果并控制执行机构。
- 最终执行机构使用两相步进电机与 TMC2209；TB6612FNG 不作为最终驱动。
- 第一版以人工回中建立零点，限制水平正负 180 度和俯仰正负 45 度。
- 采用二进制 UART 帧、CRC16/MODBUS、300 ms 通信超时停机。
- 第一版通过显示、LED 或蜂鸣器表达锁定，不使用主动光学发射器。

## 后果

- 先可快速实现视觉与控制闭环，但无编码器和限位时不能自动恢复真实绝对位置。
- 机械线束、逻辑电平和驱动细节必须经实物核验，否则不得上电。
- 后续若加限位开关或编码器，需建立新的 ADR 并更新验收要求。
