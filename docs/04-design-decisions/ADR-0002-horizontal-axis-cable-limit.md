# ADR-0002：水平轴改用正负 90 度软件限位

## 状态

已采纳为当前装配设计；完整机械行程和边界余量待实测。

## 背景

已将视觉模块、屏幕和线束组装为二维云台成品。已确认当前 X42S 安装在水平轴，水平旋转会受到线束扭转影响；继续沿外侧运动可能损伤线束。俯仰方向暂未发现同样的线束约束，但机械行程尚未完成核验。

## 决策

- 水平轴人工回中位置定义为 `0°`。
- 当前装配的水平软件限值定义为 `-90°` 到 `+90°`。
- X42S 当前 16 细分为 `3200 脉冲/圈`，因此软件边界换算为 `-800` 到 `+800` 脉冲。
- 位置无效或目标超出边界时，拒绝启动新的外向运动；边界内的反向运动允许。
- 俯仰轴暂不写入数值限位；待机械行程和线束状态核验后另行决策。

## 后果

- 这是防止当前线束被扭转的保护设计，不等同于机械限位开关，也不代表编码器真实角度。
- 细分、电机安装方向或水平线束布局变化后，必须重新核验脉冲边界。
- 没有编码器和限位开关时，掉电、堵转、手动转动或丢步后仍必须人工回中。
