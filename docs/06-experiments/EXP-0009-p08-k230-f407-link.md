# EXP-0009：P08 K230-F407 视觉通信链路

## 基本信息

- 实验编号：EXP-0009
- 日期：2026-08-23
- 状态：文本过渡链路和视觉误差计算已实测；正式二进制协议待完成。
- 分支：`feature/f407-p08-k230-link`

## 目标

验证 K230 标准版专用通信口到 F407 USART2 的接线、DMA 分段接收、文本行拼接、视觉字段解析、画面中心误差和水平速度目标计算。

## 硬件与接线

依据 K230 标准版接口资料和已确认接线：

```text
K230 IO9 / TX1  -> F407 PA3 / USART2_RX
K230 IO10 / RX1 <- F407 PA2 / USART2_TX
K230 GND        -> F407 GND
```

K230 运行 `firmware/k230/app/p04_face_result_publisher.py`，F407 使用 USART2 115200、8N1、RX DMA Normal、Receive-to-Idle。

## 操作与结果

1. 初次下载后保持 K230 未运行：`frames=0`，F407 主循环和诊断日志正常。
2. 运行 K230 P04 发布器：`frames` 持续增加，`cx/cy` 随目标变化。
3. 观察 DMA 分段：出现 `last_size=6/15/35` 等短片段，确认不能把 DMA 回调直接当完整文本帧。
4. 加入按换行拼行后重新实测：`frames=837`、`drop=0`、`text_ok=828`、`text_err=9`。
5. 无目标时观察到 `target=0` 且误差与速度目标清零。
6. 目标偏左/偏右时观察 `err_x` 正负和 `pan_speed` 正负，方向映射按实测结果取反。
7. 使用 Logic 2 在 F407 PA3/USART2_RX 端采样，第二次采样持续约 19.6 s，解码得到 555 条完整 `PV04` 行，未出现 `0xFF`。
