# EXP-0006：P05 单轴闭环电机验收台

## 基本信息

- 实验编号：EXP-0006
- 日期：2026-08-21
- 状态：板上实测通过；波形和温度数值待仪器补测。
- 目标：验证单轴 X42S 的 STEP/DIR/EN 控制、方向定义、固定脉冲运动、加减速和人工理论零点。
- 固件分支：`feature/f407-uart-dma-lab`

## 硬件与接线

- F407：正点原子探索者 V3。
- 电机：张大头 ZDT X42S 第二代闭环步进电机 A 款，脉冲 + 串口 TTL。
- 电机电源：可调电源 `12.0 V`，初始限流 `1.0 A`。
- `X42S Gnd -> F407 P9-43/44 GND`。
- `X42S Stp -> F407 P9-4 PB6 TIM4_CH1`。
- `X42S Dir -> F407 P9-3 PB7`。
- `X42S En -> F407 P9-8 PG15`。
- `X42S Com` 当前不接；电机电源负极与 F407 逻辑地共地。

## 配置参数

- MCU 时钟：`16 MHz HSI`。
- TIM4：`Period=9`、`Pulse=5`。
- 连续运行：`Prescaler=3199`，理论 `500 Hz`。
- 固定运动：阶段频率为 `100/200/300/400/500/400/300/200/100 Hz`。
- 300 Hz 阶段实际约 `300.019 Hz`，因为当前 16 MHz 时钟不能整除得到精确 300 Hz。
- X42S：16 细分、`3200 脉冲/圈`；90 度目标为 `800 脉冲`。

## 操作步骤与结果

1. 已确认电机菜单为 `P_Pul=PUL_ENA`、`En=H`。
2. KEY0 启动连续运行，约 500 Hz 运行后再次按 KEY0 停止；已通过。
3. 停机后 KEY1 切换方向；从输出轴正面观察，Low 为逆时针、High 为顺时针；已通过。
4. 运行中按 KEY1；电机不换向并输出拒绝日志；已通过。
5. KEY2 执行 800 脉冲加减速轨迹，约转 90 度后自动停止；已通过。
6. KEY_UP 在人工对准后建立理论零点；完整 KEY2 运动后输出理论位置；已通过。
7. 连续运行约 30 秒后停止；未见异常运动、报警或明显温升；温度数值未测。
