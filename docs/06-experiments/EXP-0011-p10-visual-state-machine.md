# EXP-0011：P10 双轴视觉状态机与 TFT 仪表盘

## 基本信息

- 实验编号：EXP-0011
- 目标：验证双轴视觉状态转换、500 ms 锁定提示、无目标/断线/越界安全停止，以及 TFT 状态仪表盘。
- 日期：2026-08-23

## 硬件与接线

- 硬件版本：STM32F407、标准版 K230、两台 X42S 闭环步进电机、MSP2834 TFT/FT6336G 触摸。
- 接线：沿用 P07、P08、P10 已实测接线；K230 通过已验证 UART 接入 F407，TFT 使用 SPI1，触摸使用 I2C1。
- 供电：电机电源与 F407 逻辑电源分开，共地；上电前保持人工回中条件。

## 操作与结果

1. 下载固件，打开 USART1 日志，确认 `PanView P10 boot`。
2. 两轴人工回中，按 `KEY_UP`，确认位置有效并接管电机。
3. 无目标运行：预期状态为 `SEARCH`，两轴 STEP 停止。
4. 目标偏离中心：预期状态为 `TRACKING`，`err_x/err_y` 与 `pan_speed/pitch_speed` 有符号变化，两轴按对应方向运动。
5. 保持目标在死区内至少 500 ms：预期出现 `VIS state=LOCKED reason=centered_for_500ms`，屏幕状态块变绿且两轴停止抖动。
6. 移出目标或让 K230 输出无目标帧：预期回到 `SEARCH` 并停止运动。
7. 停止 K230 或拔除通信线：超过 300 ms 预期进入 `LOST`，停止运动。
8. 让目标继续要求越过软件边界：预期进入 `FAULT`，停止 STEP 并释放 EN。
9. 触摸 `MODE/TAKE/STOP/INFO`：预期按钮动作与 P10 触摸记录一致，屏幕顶部状态和串口日志保持一致。
