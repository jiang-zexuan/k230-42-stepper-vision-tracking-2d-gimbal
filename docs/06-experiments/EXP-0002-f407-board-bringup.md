# EXP-0002：P01 F407 板级诊断台

## 基本信息

- 实验编号：EXP-0002
- 目标：验证 F407 的 SWD 下载调试、DS0 输出、KEY0 输入和 USART1 诊断日志最小闭环。
- 日期：2026-08-15
- 状态：部分实测；递增计数器和原始串口导出待补。

## 硬件与接线

- 硬件版本：探索者 V3.2，STM32F407ZGT6；板卡身份由用户现场确认。
- 调试：外置 ST-Link 使用 SWD，下载和调试成功。
- 串口：板载 CH340C 枚举为 `COM8`；USART1 使用 115200 bit/s、8N1、无流控。
- 供电：开发板在本轮实验中正常上电；未记录独立电压测量值。

## 固件与配置

- 工程：`firmware/stm32f407/PanViewF407/`，基线提交 `5339c42`。
- 调试接口：SYS Serial Wire；PA13 为 SWDIO，PA14 为 SWCLK。
- LED：PF9，推挽输出，初始高电平；DS0 为低电平点亮。
- 按键：PE4，输入上拉；KEY0 为低电平有效。
- 串口：USART1，PA9 为 TX、PA10 为 RX。

## 操作与结果

1. 使用 ST-Link 启动 CubeIDE Debug，在 `main()` 和 KEY0 读取代码处设置断点。
   - 预期：下载成功，CPU 可停止，变量可查看。
   - 实际：下载校验成功；用户确认曾在断点查看 KEY0 状态。
2. 未按和按住 KEY0 时单步执行 `HAL_GPIO_ReadPin()`。
   - 预期：分别读取 `GPIO_PIN_SET` 和 `GPIO_PIN_RESET`。
   - 实际：用户确认观察结果符合预期。
3. 下载运行后短按 KEY0，并观察 DS0 与串口。
   - 预期：DS0 每次有效按下切换一次，串口显示一次 `KEY0 pressed`。
   - 实际：用户确认符合预期。
4. 打开 `COM8` 串口助手后复位开发板。
   - 预期：显示 `PanView P01 boot`，并周期显示 `PanView alive`。
   - 实际：用户确认符合预期；RESET 后启动日志再次出现。

## 证据与结论

- 原始证据：本轮未从串口助手导出原始 `.log` 文件；上述串口结果为用户现场观察转录，不能替代原始串口导出。
- 问题与原因：CubeIDE 调试器对包含中文的工程路径出现启动汇编源码定位失败；烧录校验仍成功。该问题只影响源码定位，未证明影响目标程序执行。
- 结论：SWD、DS0、KEY0、USART1 启动/事件/固定心跳日志的功能闭环已实测。递增计数器和原始串口日志待补，因此本实验未达到完整可追溯验收。
- 下一步：实现递增心跳计数器，导出原始串口日志，并更新 TEST-0001 与 REQ-010 状态。
