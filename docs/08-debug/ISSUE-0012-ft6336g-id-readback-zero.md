# ISSUE-0012：FT6336G 识别寄存器读回全 0

## 状态

- 日期：2026-08-23
- 状态：待解释，不影响触摸点和 UI 已通过的结论
- 关联阶段：P10

## 现象

启动日志出现：

```text
TOUCH probe=ok id_low=00 id_high=00 vendor=00 points=0
```

其中 `probe=ok` 表示 I2C 地址收到了 ACK；`points=0` 表示启动时没有触摸。`id_low/id_high/vendor` 全为 0，与 `FT6336G_Register/full.md` 中 `0xA0=0x01`、`0xA3=0x64`、`0xA8=0x11` 的默认值不一致。

## 排查边界

已经确认触摸时能够读出 `count=1` 和有效坐标，因此不能把“识别寄存器全 0”直接归因于 I2C 接线或触摸芯片损坏。具体是芯片兼容版本、寄存器访问差异还是模块读回链路差异，当前不确定。

## 下一步

在不影响当前触摸功能的前提下，后续可用逻辑分析仪观察寄存器地址和读回字节，或对照模块官方触摸示例确认识别寄存器读取方式。
