# 项目章程

## 项目名称

基于 K230 视觉模块与 42 步进电机的视觉跟踪二维云台（PanView）。

## 目标

以 K230 运行目标检测，以 STM32F407 和 FreeRTOS 完成可靠的 UART 接收、双轴步进控制、状态管理和故障保护，形成可演示、可测试、可追溯的校招项目。

## 范围

- 第一版跟踪单一已定义类别，显示或声光提示锁定。
- 当前装配下水平轴软件范围设计为 -90 到 +90 度，依据为线束扭转约束；俯仰轴数值范围待机械行程核验，不能假设无限旋转。
- 上电人工回中作为当前软件零点。X42S 驱动器内部带磁编码器闭环，但 F407 尚未接入 TTL 反馈；在没有外部反馈读取和机械限位的阶段，堵转、掉电或位置可信度丢失后仍必须重新人工回中。
- 本项目不包含主动光学发射器、连续无限旋转或自主安全决策。

## 当前硬件

- 已有：正点原子 STM32F407 探索者开发板。
- 已有：Yahboom AIMOTION2 K230 标准版视觉模块。
- 已有：TB6612FNG；仅用于基础电机实验，不是最终步进电机驱动方案。
- 待购：两台 NEMA17 步进电机、两块 TMC2209、双轴 NEMA17 云台、12 V 5 A 可调限流电源。具体型号待购买后核验。
