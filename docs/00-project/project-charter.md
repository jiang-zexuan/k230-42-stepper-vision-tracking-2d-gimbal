# 项目章程

## 项目名称

基于 K230 视觉模块与 42 步进电机的视觉跟踪二维云台（PanView）。

## 目标

以 K230 运行目标检测，以 STM32F407 和 FreeRTOS 完成可靠的 UART 接收、双轴步进控制、状态管理和故障保护，形成可演示、可测试、可追溯的开源工程。

## 范围

- 第一版跟踪单一已定义类别，显示或声光提示锁定。
- 当前最终装配下，水平轴和俯仰轴软件范围均设计为 -90 到 +90 度；该范围是软件安全边界，不能假设机械无限旋转。
- 上电人工回中作为当前软件零点。X42S 驱动器内部带磁编码器闭环，F407 已接入 TTL 反馈用于诊断；控制坐标仍以回中后的 STEP 累计为主，堵转、掉电或位置可信度丢失后仍必须重新人工回中。
- 项目包含受控光学指示模块：由 PF10 控制，仅在命中提示期间开启，并在音效结束、停止、故障或复位时关闭；不涉及激光瞄准、危险光源、连续无限旋转或自主安全决策。

## 当前硬件

- 已有：正点原子 STM32F407 探索者开发板。
- 已有：Yahboom AIMOTION2 K230 标准版视觉模块。
- 已有：两台 X42S 闭环步进电机/驱动器组合；当前已核验 STEP/DIR/EN 和 TTL 通信链路，反馈读取仍按轴分别验证。
- 已有：Yahboom AIMOTION2 K230 标准版、ILI9341/FT6336G TFT 触摸屏、ES8388 音频模块、ST-Link、USB 逻辑分析仪和 12 V 可调电源。
- 已有：TB6612FNG；仅用于基础电机实验，不是最终步进电机驱动方案。
- 待补齐：自定义模型数据集、模型部署参数和最终长时间运行测试证据。
