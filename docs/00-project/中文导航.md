1. 先读[项目化学习规划书](project-based-learning-plan.md)，了解 P01 到 P12 的目标与验收条件。
2. 再读[学习地图](learning-map.md)，把每个小项目放回最终双轴跟踪云台的数据流中理解。
3. 进入当前固件工程：[PanViewF407](../../firmware/stm32f407/PanViewF407)。手写学习代码位于 `Core/Inc`、`Core/Src` 和 `Tests`；CubeMX/ST 自动生成代码保持原样。

## 关键术语

| 英文术语 | 中文理解 |
| --- | --- |
| GPIO | 通用输入输出引脚；本项目中用于读取 KEY0、控制 DS0。 |
| UART / USART | 串行通信外设；USART1 经 CH340C 与 PC 串口相连。 |
| HAL | ST 提供的硬件抽象层；例如 `HAL_GetTick()` 读取毫秒时间。 |
| SysTick | Cortex-M 的系统节拍定时器；HAL 默认用它产生毫秒时间基准。 |
| 非阻塞 | 不在等待期间停住 CPU；例如用时间差判断 20 ms 是否已过去。 |
| 状态机 | 用变量保存“现在处于哪一步”，让程序按事件与时间推进。 |
| DMA | 直接存储器访问；外设可把数据搬入内存，减少 CPU 逐字节参与。 |
| CRC | 循环冗余校验；通信中用于判断一帧数据是否被破坏。 |
