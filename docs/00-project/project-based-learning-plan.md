# PanView 项目化学习规划书

## 使用方式

本规划把最终的边缘视觉双轴跟踪云台拆成 12 个由易到难、可独立演示的小项目。每次只推进一个项目；通过验收并留下证据后，才进入下一项。

每个项目必须有：

- 一份实验或测试记录。
- 一个单一目的的 Git 提交。
- 串口日志、照片、逻辑分析仪波形或短视频中的至少一种证据。
- 一段能说清输入、处理、输出和异常处理的口头说明。

状态约定：

- 当前可做：只依赖已经拥有的 F407 或 K230。
- 等待电机：需要闭环电机、驱动板或云台到货。
- 待验证：参数或接线尚未通过实物、手册与实验三者核验。

## 最终项目

系统数据流：摄像头 -> K230 检测目标 -> UART 目标数据 -> STM32F407 + FreeRTOS -> 两轴闭环步进驱动 -> 云台。

F407 同时负责 LED、屏幕或蜂鸣器的锁定和故障提示。

最终演示：人工回中后，K230 检测指定目标；F407 在软件范围内控制双轴云台跟随；稳定居中后提示 LOCKED；目标丢失、通信超时或异常状态时停止运动并保留故障记录。

## P01：F407 板级诊断台

目标：建立后续所有 F407 小项目共用的 STM32CubeIDE 工程骨架。

只做这些事：

1. 在官方或开发板资料核验后创建 CubeMX 工程。
2. 点亮一个状态 LED，按键改变 LED 状态。
3. 配置一个调试串口，周期输出启动信息、计数器和按键事件。
4. 用 ST-Link 下载、单步、查看变量和断点。

验收：

- 上电后 LED 有确定状态，按键事件可在串口观察。
- 复位后串口重新输出启动日志。
- 保存 ioc、原理图依据、工程提交和一份串口日志。

下一项目接口：最小板级 LED、按键、UART 日志接口。

## P02：非阻塞定时任务台

目标：理解时间到了做事与延时卡住 CPU 的差异，为运动控制和 FreeRTOS 做准备。

只做这些事：

1. 使用 SysTick 或硬件定时器建立 1 ms 时间基准。
2. 实现 10 ms、100 ms、500 ms 的非阻塞周期任务。
3. 同时执行 LED 心跳、按键扫描、串口状态输出。
4. 记录中断频率和任务实际周期。

验收：

- 三种周期任务并行运行，按键响应不因 LED 闪烁或日志输出而丢失。
- 用串口时间戳或逻辑分析仪证明周期大致正确。

下一项目接口：毫秒时间基准和非阻塞软件定时器思路。

## P03：UART DMA 协议实验器

目标：先用 PC 串口模拟视觉模块，把最难排错的通信问题提前解决。

只做这些事：

1. 配置 UART DMA 接收和空闲中断或等价收包机制。
2. 先实现可读文本命令，再实现二进制帧。
3. 实现帧头重同步、长度检查、CRC16/MODBUS、帧序号和错误计数。
4. 用 PC 故意发送半帧、粘包、垃圾字节、错误 CRC 和超时。

验收：

- 正常帧正确解析。
- 错帧只增加错误计数，不改变最后一次有效目标。
- 随后的正常帧能自动恢复解析。

下一项目接口：可复用的视觉协议驱动和主机测试向量。

## P04：K230 视觉结果发布器

目标：K230 独立完成检测和结果输出，不依赖 F407。

只做这些事：

1. 跑通一个供应商现成检测模型。
2. 在屏幕或 IDE 中观察检测框、类别和置信度。
3. 记录图像分辨率、FPS、目标中心坐标和无目标状态。
4. 通过 UART 先输出文本格式结果。

验收：

- 正常光照下能持续识别指定演示目标。
- 输出中有时间、是否有目标、中心坐标、宽高、置信度和 FPS。
- 结论只以录屏或串口原始日志为依据。

下一项目接口：明确 K230 实际输出频率、坐标范围和 UART 可用引脚。

## P05：单轴闭环电机验收台

前提：闭环电机、驱动器与电源到货。若购买张大头闭环套装，必须核验具体型号、手册、是否已安装编码器板、供电范围和信号端子。

目标：不接视觉、不装云台，安全地让一台电机受 F407 控制。

只做这些事：

1. 按手册完成驱动器供电、逻辑共地和低电流上电检查。
2. 使用 STEP/DIR/EN 完成使能、低速正转、反转和停止。
3. 记录每圈脉冲数、方向定义和实际转动方向。
4. 检查电机与驱动器温升、报警、堵转或编码器校准状态。

验收：

- F407 输出一个可测量的 STEP 波形，电机运动方向与软件定义一致。
- 停止、失能和异常状态不会继续输出运动脉冲。
- 电源、端子、脉冲电平、细分和电流设置均有资料或实测来源。

下一项目接口：单轴使能、方向设置和脉冲输出硬件配置。

## P06：单轴运动控制器

目标：把发脉冲提升为移动到指定角度且不越界。

只做这些事：

1. 建立脉冲数到电机角度再到云台角度的换算表。
2. 实现人工回中确认，把当前位置定义为软件零点。
3. 实现相对移动、绝对移动、最大速度和梯形加减速。
4. 实现水平轴正负 180 度的软件限位。

验收：

- 输入小角度、较大角度和反向移动命令时，方向与累计位置一致。
- 对越界命令拒绝继续向外运动并记录原因。
- 断电、松动、堵转或丢失可信位置后，要求重新人工回中。

下一项目接口：单轴移动、停止和回中状态接口。

## P07：双轴云台基础控制器

目标：先让云台成为可靠的执行机构，再把视觉接上来。

只做这些事：

1. 定义水平轴和俯仰轴的正方向、零点和角度范围。
2. 实现两轴独立移动与受限同步移动。
3. 低速进行全行程测试，检查线束扭转、结构干涉、松动和发热。
4. 俯仰轴限制在正负 45 度。

验收：

- 两轴命令、实物方向和软件累计位置一致。
- 任何单轴或组合命令均不能突破软件范围。
- 全行程测试有照片或视频，以及线束状态结论。

下一项目接口：双轴移动和全轴停止接口。

## P08：K230-F407 正式通信链路

目标：用已在 P03 验证的解析器连接真实 K230，取代文本调试协议。

只做这些事：

1. 根据实物丝印和手册核验 K230 UART3 与 F407 UART 的真实接线。
2. 固定二进制帧版本、长度语义、字段编码、CRC 覆盖范围和无目标状态。
3. 测量有效帧率、端到端时延、丢帧和错误计数。
4. 验证 300 ms 无有效帧时 F407 进入 LOST。

验收：

- F407 的日志显示正确的目标坐标和帧序号。
- K230 断线、坏帧或停止发送后，F407 不更新运动目标。
- 真实帧日志与协议文档中的字段表对应。

下一项目接口：最新 VisionTarget 数据。

## P09：单轴视觉跟踪器

目标：构成第一版视觉运动闭环，只控制水平轴。

只做这些事：

1. 将画面中心与目标中心的 X 偏差转换为水平轴速度目标。
2. 实现死区、比例系数、最大速度和最小有效置信度。
3. 目标离开画面或通信超时后，在 300 ms 内停止。
4. 用静止和缓慢移动目标分别调参。

验收：

- 目标偏左时水平轴向正确方向运动，偏右时相反。
- 进入画面中心死区后电机不会来回高频抖动。
- 失去目标后无持续运动。

下一项目接口：可配置的目标跟踪控制器。

## P10：双轴视觉跟踪器

目标：实现 PanView 的核心可演示版本。

只做这些事：

1. 在 P09 的基础上加入 Y 偏差到俯仰轴的映射。
2. 处理图像坐标与云台正方向不一致的问题。
3. 定义 SEARCH、TRACKING、LOCKED、LOST、FAULT 状态转换。
4. 目标稳定居中 500 ms 后输出 LED、屏幕或蜂鸣器锁定提示。

验收：

- 两轴能将目标保持在画面中心附近。
- 稳定中心误差目标为画面宽高的 5% 以内，必须通过实测记录确认。
- 无目标、通信异常和越界时均先停止运动。

下一项目接口：第一个端到端演示版本。

## P11：FreeRTOS 与故障管理

目标：把已验证的裸机功能迁移为可维护的实时工程，而不是在不稳定时引入 RTOS。

计划任务：

- VisionRxTask：UART DMA、组帧和 CRC。
- MotionTask：10 ms 目标速度计算。
- StepperTask：定时器脉冲与加减速。
- SafetyTask：10 ms 超时、限位、心跳检查。
- TelemetryTask：100 ms 日志和统计。
- StatusTask：状态提示。

验收：

- 有任务优先级、栈余量和周期记录。
- 停止运动的安全路径不依赖低优先级日志任务。
- 模拟任务失活、通信超时和软件越界时有故障码与预期安全动作。

## P12：自定义模型与系统交付

目标：完成可用于公开展示的最终版本。

只做这些事：

1. 采集、标注与训练一个明确的自定义目标类别。
2. 在 K230 上部署模型，记录输入尺寸、量化方式、FPS 与置信度阈值。
3. 进行断线、错帧、低置信度、软件越界、堵转或报警和长时间运行测试。
4. 完善架构图、测试报告、演示视频、项目描述和工程问题。

验收：

- 正常光照下检测输出不低于 20 FPS，需保留实测证据。
- 连续运行 2 小时无已知死机、栈溢出或非预期复位。
- 需求追踪矩阵能从每个验收项链接到代码提交、测试步骤与证据。

## 当前执行顺序

电机到货前，只推进 P01、P02、P03、P04；电机到货后按顺序完成 P05，再进入 P06。

建议节奏：

1. 先完成 P01 的 LED、按键、串口日志和调试下载。
2. 接着完成 P02，建立非阻塞定时器思维。
3. 完成 P03 后，F407 已具备接收视觉数据的关键能力。
4. 并行做 P04，确认 K230 的真实模型输出和 UART 行为。
5. P05 已完成单轴电机验收，当前进入 P06，不跳过软件限位和人工回中。

## 不提前做的事

- 在未完成 P05 前，不向电机发送视觉跟踪命令。
- 在未完成 P03 前，不把真实 K230 通信错误归因到视觉模型。
- 在未完成 P06 和 P07 前，不做双轴自动跟踪。
- 在裸机版本没有稳定验收前，不迁移 FreeRTOS。
- 在没有实测证据前，不把驱动器接口、电压、细分、额定电流、机械行程或性能写成已确认事实。
