# 16 周路线图

| 周次 | 阶段 | 知识与实践产出 |
| --- | --- | --- |
| 1-2 | 基线与外设复习 | 仓库、C 语言复习、GPIO、UART、定时器、DMA 板级自检 |
| 3-4 | 裸机运动控制 | 两轴步进控制、梯形加减速、角度换算、软件限位 |
| 5-6 | K230 视觉 | 运行现成模型，记录坐标、FPS、置信度 |
| 7 | 通信联调 | 文本协议原型后切换二进制帧、CRC 和错帧恢复 |
| 8-9 | 单轴闭环 | 水平单轴死区、比例控制、速度限制 |
| 10 | 双轴跟踪 | 水平和俯仰的双轴协同跟踪 |
| 11-12 | FreeRTOS | 任务迁移、优先级、栈余量和周期记录 |
| 13 | 自定义模型 | 数据采集、标注、训练、量化与 K230 部署 |
| 14 | 安全与容错 | 超时、软件越界、心跳、看门狗、故障码 |
| 15 | 系统验证 | 参数调优、故障注入、两小时运行 |
| 16 | 交付材料 | README、架构图、测试报告、演示材料 |

每周在 docs/05-learning-log/weekly/ 建立一份日志，记录知识、提交、实测证据、遗留问题和下周目标。
