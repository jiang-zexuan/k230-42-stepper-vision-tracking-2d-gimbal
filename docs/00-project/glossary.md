# 术语表

| 术语 | 含义 |
| --- | --- |
| K230 | 运行视觉模型并输出目标结果的边缘 AI 模块主控。 |
| F407 | STM32F407，负责实时控制、通信和安全逻辑。 |
| STEP/DIR | 步进驱动器常用脉冲和方向控制接口。 |
| X42S | 42 系列闭环步进电机/驱动器组合，内置磁编码器与 FOC；F407 通过 STEP/DIR/EN 控制。 |
| UART | 异步串行通信接口。 |
| DMA | 外设直接搬运数据到内存，减少 CPU 字节搬运。 |
| CRC16/MODBUS | 用于识别传输错误的 16 位循环冗余校验。 |
| 死区 | 目标偏差较小时不驱动电机的范围，用于抑制抖动。 |
| 软件限位 | 在位置估算值超过定义范围前拒绝继续向外运动。 |
| 人工回中 | 操作者把云台放到机械中位，并由软件将其记为零点。 |
