# 系统架构

## 设计基线

摄像头 -> K230 检测与坐标提取 -> 专用 UART -> STM32F407 + FreeRTOS -> STEP/DIR/EN -> X42S 闭环步进组合 x2 -> 两轴云台。

F407 同时负责 TFT/触摸、命中特效音和 PF10 光学指示。K230 独立运行视觉模型；F407 不运行视觉推理，只处理 UART 结果、生成受限运动命令并执行安全策略。

## 供电设计基线

- K230 在第一版中通过自身 5 V USB 供电。
- F407 在第一版中通过 USB 供电。
- 两个步进驱动器和电机由独立 12 V 电源供电。
- 联调信号前，K230、F407 与电机驱动的逻辑地必须共地。

两台 X42S 均为带磁编码器和 FOC 的闭环组合；F407 的控制坐标仍以人工回中后的 STEP 累计为主，反馈读取用于诊断。水平与俯仰软件范围均为 ±90°，两轴电源使用独立 12 V，逻辑设备与驱动器必须共地。
