# 系统架构

## 设计基线

摄像头 -> K230 检测与坐标提取 -> UART -> STM32F407 + FreeRTOS -> STEP/DIR -> TMC2209 x2 -> 两轴步进云台。

F407 同时负责屏幕、LED 或蜂鸣器锁定提示。K230 独立运行视觉模型；F407 不运行视觉推理，只处理 UART 结果、生成受限运动命令并执行安全策略。

## 供电设计基线

- K230 在第一版中通过自身 5 V USB 供电。
- F407 在第一版中通过 USB 供电。
- 两个步进驱动器和电机由独立 12 V 电源供电。
- 联调信号前，K230、F407 与电机驱动的逻辑地必须共地。

电机型号、TMC2209 模块版型、逻辑电平和具体供电接法均待实物与资料核验后确认。
