## 1. 任务需求说明

### 1.1 T08 要解决什么问题

系统出现通信中断、控制任务停止、限位状态异常或人工急停时，电机必须停止，不能继续执行旧命令。故障还要被锁存，避免故障刚出现又被普通状态覆盖。

### 1.2 输入

- MotionTask 的心跳计数和最近运行时间。
- 步进模块的理论位置与当前执行速度。
- UART HAL 错误回调提供的错误码。
- KEY0 按键下降沿产生的软件急停请求。
- IWDG 的正常喂狗动作。

### 1.3 输出

- 当前安全状态：故障类型、是否锁存、故障发生时间。
- 安全停机动作：停止双轴 STEP、清零执行速度、释放两路 EN。
- 看门狗复位：SafetyTask 长时间失活时由 IWDG 复位芯片。

### 1.4 依赖的硬件/底层模块

- STM32F407 GPIO：电机 EN、STEP、KEY0。
- TIM3/TIM4：步进脉冲输出。
- USART2 + DMA：接收 K230 数据。
- FreeRTOS/CMSIS-RTOS：SafetyTask、任务心跳和周期延时。
- STM32F407 IWDG：检测 SafetyTask 是否长期失活。

## 2. 解耦后的最小可阅读代码

### 2.1 `panview_safety.h`

```c
#ifndef PANVIEW_SAFETY_H
#define PANVIEW_SAFETY_H

#include <stdint.h>

/* 系统能够识别的安全故障类型。 */
typedef enum
{
  PANVIEW_SAFETY_CLEAR = 0,
  PANVIEW_SAFETY_CONTROL_TASK_STALE,
  PANVIEW_SAFETY_SOFTWARE_LIMIT,
  PANVIEW_SAFETY_UART_ERROR,
  PANVIEW_SAFETY_EMERGENCY_STOP
} PanViewSafetyFault;

/* 对外公开的安全状态快照。 */
typedef struct
{
  PanViewSafetyFault fault; /* 第一次发生的故障类型。 */
  uint8_t latched;          /* 1=已经锁存，0=当前无故障。 */
  uint32_t fault_tick_ms;   /* 故障发生时的系统毫秒计数。 */
} PanViewSafetyStatus;

void PanView_Safety_Init(void);
void PanView_Safety_RaiseFault(PanViewSafetyFault fault, uint32_t tick_ms);
void PanView_Safety_RequestEmergencyStop(uint32_t tick_ms);
void PanView_Safety_GetStatus(PanViewSafetyStatus *status);
void PanView_Safety_ClearFault(void);

#endif
```

### 2.2 `panview_safety.c`

```c
#include "panview_safety.h"

/* 模块内部保存唯一一份安全状态，外部只能通过接口访问。 */
static PanViewSafetyStatus safety_status;

void PanView_Safety_Init(void)
{
  safety_status.fault = PANVIEW_SAFETY_CLEAR;
  safety_status.latched = 0U;
  safety_status.fault_tick_ms = 0U;
}

void PanView_Safety_RaiseFault(PanViewSafetyFault fault, uint32_t tick_ms)
{
  /* CLEAR 不是故障请求。 */
  if (fault == PANVIEW_SAFETY_CLEAR)
  {
    return;
  }

  /* 只保存第一次故障，保留最初原因。 */
  if (safety_status.latched == 0U)
  {
    safety_status.fault = fault;
    safety_status.fault_tick_ms = tick_ms;
    safety_status.latched = 1U;
  }
}

void PanView_Safety_RequestEmergencyStop(uint32_t tick_ms)
{
  PanView_Safety_RaiseFault(PANVIEW_SAFETY_EMERGENCY_STOP, tick_ms);
}

void PanView_Safety_GetStatus(PanViewSafetyStatus *status)
{
  if (status != 0)
  {
    *status = safety_status;
  }
}

void PanView_Safety_ClearFault(void)
{
  safety_status.fault = PANVIEW_SAFETY_CLEAR;
  safety_status.latched = 0U;
  safety_status.fault_tick_ms = 0U;
}
```

### 2.3 SafetyTask 最小示例

```c
void SafetyTask_RunOnce(uint32_t now_ms)
{
  PanViewSafetyStatus status;

  PanView_Safety_GetStatus(&status);

  /* 只要故障已经锁存，就调用统一停机接口。 */
  if (status.latched != 0U)
  {
    PanView_Stepper_SafetyStop();
  }

  /* 正式工程中这里还会调用 HAL_IWDG_Refresh(&hiwdg)。 */
  (void)now_ms;
}
```

### 2.4 KEY0 测试触发器

```c
void SafetyTest_Key0Scan(GPIO_PinState key0_state,
                         GPIO_PinState *previous_state,
                         uint32_t now_ms)
{
  /* KEY0 使用上拉输入，按下时为低电平。 */
  if ((key0_state == GPIO_PIN_RESET) &&
      (*previous_state == GPIO_PIN_SET))
  {
    PanView_Safety_RequestEmergencyStop(now_ms);
  }

  *previous_state = key0_state;
}
```

## 3. 代码拆解讲解

### 3.1 变量和结构体成员

- `safety_status`：安全模块的私有全局状态，只允许本模块修改。
- `fault`：保存第一次发生的故障类型。
- `latched`：故障锁存标志。为 1 后，普通运行不会自动清除。
- `fault_tick_ms`：记录故障发生时刻，便于日志和定位。
- `status`：SafetyTask 的局部状态快照，不直接暴露内部变量。
- `key0_state`：本次读取到的 KEY0 电平。
- `previous_state`：上一次 KEY0 电平，用于判断按下沿而不是重复触发。

### 3.2 对外公开接口

- `PanView_Safety_Init()`：系统启动时调用一次，清空故障状态。
- `PanView_Safety_RaiseFault()`：UART、心跳、限位等故障来源调用；只锁存第一次故障。
- `PanView_Safety_RequestEmergencyStop()`：输入任务或测试程序调用，注入软件急停。
- `PanView_Safety_GetStatus()`：SafetyTask、UI 或遥测读取只读快照。
- `PanView_Safety_ClearFault()`：确认复位条件满足后清除故障。
- `PanView_Stepper_SafetyStop()`：步进执行模块提供的统一停机接口，不属于安全状态模块本身。

### 3.3 内部私有函数

本最小安全状态模块没有额外私有函数。把逻辑保持简单，便于初学者追踪。

### 3.4 完整执行流程

1. 系统启动调用 `PanView_Safety_Init()`。
2. 某个故障来源调用 `PanView_Safety_RaiseFault()`。
3. 模块保存第一次故障并置 `latched=1`。
4. SafetyTask 周期读取状态。
5. 发现锁存故障后调用 `PanView_Stepper_SafetyStop()`。
6. 步进模块停止 STEP、清零速度、释放 EN。
7. IWDG 由 SafetyTask 周期喂狗；如果 SafetyTask 自身失活，IWDG 最终复位芯片。

### 3.5 嵌入式开发坑点

1. **故障锁存不是自动恢复**：按键松开不会清除急停，必须复位或明确调用清除接口。
2. **IWDG 与断点冲突**：断点暂停 CPU 后 SafetyTask 无法喂狗，可能触发复位；不要在喂狗函数上长时间停留。
3. **UART 错误与环形缓冲区不同**：UART ORE 发生在硬件接收寄存器层，恢复后只能继续接收，已经丢失的字节无法找回。
4. **栈溢出要开启官方检查**：`FreeRTOSConfig.h` 中保留 `configCHECK_FOR_STACK_OVERFLOW 2`，并结合 `uxTaskGetStackHighWaterMark()`。
5. **CubeMX 配置必须同步**：`VisionRxTask` 的 1024 Words 要在 `.ioc` 中配置，否则重新生成代码可能覆盖手工修改。
6. **安全停机不能依赖 UI、音频或遥测**：SafetyTask 应独立完成停机动作。
7. **变量并发访问要谨慎**：如果故障来源来自中断，正式版本应增加临界区或原子保护。

## 4. main 简易测试 Demo

下面 Demo 省略 HAL 和 FreeRTOS，只演示调用关系：

```c
#include <stdio.h>
#include "panview_safety.h"

/* 用一个简单变量模拟电机是否正在运行。 */
static int motor_running = 1;

void PanView_Stepper_SafetyStop(void)
{
  motor_running = 0;
  printf("motor stopped and disabled\\n");
}

void SafetyTask_RunOnce(void)
{
  PanViewSafetyStatus status;
  PanView_Safety_GetStatus(&status);

  if (status.latched != 0U)
  {
    PanView_Stepper_SafetyStop();
  }
}

int main(void)
{
  PanViewSafetyStatus status;

  PanView_Safety_Init();
  printf("motor_running=%d\\n", motor_running);

  /* 模拟按下 KEY0。 */
  PanView_Safety_RequestEmergencyStop(1234U);
  SafetyTask_RunOnce();

  PanView_Safety_GetStatus(&status);
  printf("fault=%d latched=%u tick=%lu motor_running=%d\\n",
         (int)status.fault,
         status.latched,
         (unsigned long)status.fault_tick_ms,
         motor_running);

  return 0;
}
```

预期输出：

```text
motor_running=1
motor stopped and disabled
fault=4 latched=1 tick=1234 motor_running=0
```

这里的 `fault=4` 对应 `PANVIEW_SAFETY_EMERGENCY_STOP`。

最终安全链路：

```text
故障来源 → 安全状态锁存 → SafetyTask → 统一停机 → 电机失能
```
