# PanView T05、T06 独立学习文档

> 生成日期：2026-09-04  
> 学习目标：脱离 STM32 完整工程，只理解“串口文本如何变成视觉结果，以及视觉结果如何变成影子运动命令”。

本文把原工程中的 T05 和 T06 重新整理成最小学习代码。文中的代码不包含 CubeMX 初始化、FreeRTOS 任务创建、心跳、LED、UI、音频、电机定时器等无关内容。

完整信息流如下：

```text
K230 通过 USART2 发送 PV04 文本
        ↓
UART DMA/中断得到一批字节
        ↓
标准字节环形缓冲区
        ↓
按 \r\n 提取完整文本行
        ↓
解析为 VisionResult
        ↓
计算目标相对画面中心的误差
        ↓
死区、比例、最大速度、斜率、锁定滞回
        ↓
生成 MotionCommand（影子命令，不驱动电机）
```

---

## 1. 任务需求说明

### 1.1 T05：把 K230 串口文本转换成视觉结果

#### T05 要解决什么问题

USART 是连续的字节流，STM32 一次收到的 DMA 数据块不一定正好是一整行。例如一帧：

```text
PV04 t_ms=18278 target=1 count=1 x=771 y=0 w=528 h=786 cx=1035.0 cy=393.0 confidence=0.0000 fps=0.00\r\n
```

可能被拆成：

```text
第1次收到：PV04 t_ms=18278 target=1 co
第2次收到：unt=1 x=771 y=0 w=528 h=786 cx=1035.0
第3次收到： cy=393.0 confidence=0.0000 fps=0.00\r\n
```

因此不能假设“一次串口回调等于一帧”。T05 必须完成三件事：

1. 用环形缓冲区暂存连续到来的字节。
2. 从字节流中寻找换行符，拼出完整文本行。
3. 把 PV04 文本字段解析到 `VisionResult` 结构体。

#### T05 输入

- K230 发送的 ASCII 文本字节。
- 当前帧以 `\r\n` 结束。
- 当前识别模型输出两种帧：

```text
PV04 t_ms=17950 target=0 count=0\r\n
```

```text
PV04 t_ms=18278 target=1 count=1 x=771 y=0 w=528 h=786 cx=1035.0 cy=393.0 confidence=0.0000 fps=0.00\r\n
```

#### T05 输出

解析成功后输出一份 `VisionResult`：

- 是否存在目标。
- 目标数量。
- 目标框位置和大小。
- 目标中心坐标。
- K230 时间戳。
- STM32 当前使用的图像宽高。

#### T05 依赖的硬件和底层模块

- STM32F407。
- USART2：接收 K230 数据。
- DMA 或 UART 空闲中断：把收到的一批字节交给环形缓冲区。
- FreeRTOS `VisionRxTask`：从环形缓冲区读取并解析数据。

最小学习代码不包含 HAL/DMA 初始化，只把“底层已经收到的字节”作为输入。

### 1.2 T06：把视觉结果转换成影子运动命令

#### T06 要解决什么问题

T05 只能告诉系统“目标在哪里”，不能直接控制电机。T06 把目标位置转换为双轴速度命令：

```text
VisionResult
    ↓
目标中心 - 画面中心
    ↓
error_x_px / error_y_px
    ↓
MotionCommand
```

T06 当前是影子运行：只计算并通过 USART1 打印，不驱动 STEP、DIR、EN，也不操作电机定时器。

#### T06 输入

- T05 产生的最新一份 `VisionResult`。
- 上一周期的影子运动命令，用于速度斜率限制。
- 上一周期的锁定状态，用于锁定滞回。

#### T06 输出

一份 `MotionCommand`：

- 水平轴速度，单位 `step/s`。
- 俯仰轴速度，单位 `step/s`。
- 命令生成时间，单位 `ms`。
- 命令是否有效。

同时得到：

- X/Y 像素误差。
- 目标是否处于锁定状态。

#### T06 依赖的硬件和底层模块

- 不依赖实际电机硬件。
- 原工程中由 `MotionTask` 每 10 ms 调用。
- 原工程通过 USART1 输出 `T06_SHADOW` 日志。
- 原工程使用 CMSIS-RTOS V2 单槽消息队列传递最新 `VisionResult`。

软件位置限位没有放进 T06，因为当前电机尚未执行命令，也没有可信的累计步数和回零基准。

### 2.1 `panview_t05.h`

```c
#ifndef PANVIEW_T05_H
#define PANVIEW_T05_H

#include <stdint.h>

/*
 * 环形缓冲区数组的物理大小。
 * 为了用 read_index == write_index 表示“空”，必须保留一个空槽，
 * 所以最多实际保存 1023 字节。
 */
#define PANVIEW_RING_CAPACITY 1024U

/* 单行文本的最大存储空间，包括最后的字符串结束符 '\0'。 */
#define PANVIEW_LINE_CAPACITY 256U

/*
 * 标准字节环形缓冲区。
 * UART 接收回调只写入，主循环或 VisionRxTask 只读取。
 */
typedef struct
{
    uint8_t data[PANVIEW_RING_CAPACITY];

    /* 下一次写入字节的位置。 */
    volatile uint16_t write_index;

    /* 下一次读取字节的位置。 */
    volatile uint16_t read_index;
} PanViewRingBuffer;

/*
 * 文本行累积器。
 * 它把一个个字节暂存起来，直到收到换行符 '\n'。
 */
typedef struct
{
    char data[PANVIEW_LINE_CAPACITY];

    /* 当前已经保存了多少个正文字符。 */
    uint16_t size;

    /* 当前行过长后置 1，并一直丢弃到下一个 '\n'。 */
    uint8_t discarding;
} PanViewLineAccumulator;

/* T05 最终输出的视觉结果。 */
typedef struct
{
    /* K230 在 PV04 帧中发送的时间戳，单位 ms。 */
    uint32_t source_timestamp_ms;

    /* 目标数量和是否有可用目标。 */
    uint16_t target_count;
    uint8_t target_present;

    /* 当前视觉源图像尺寸，单位 px。 */
    uint16_t frame_width_px;
    uint16_t frame_height_px;

    /* 目标框左上角坐标，单位 px。 */
    int16_t target_x_px;
    int16_t target_y_px;

    /* 目标框宽高，单位 px。 */
    uint16_t target_width_px;
    uint16_t target_height_px;

    /* 目标中心坐标，单位 px。 */
    float center_x_px;
    float center_y_px;
} VisionResult;

/* 初始化环形缓冲区。 */
void PanView_Ring_Init(PanViewRingBuffer *buffer);

/* 写入一批字节，返回实际成功写入的字节数。 */
uint16_t PanView_Ring_Write(PanViewRingBuffer *buffer,
                            const uint8_t *input,
                            uint16_t length);

/* 读取一个字节。成功返回 1，没有数据或参数错误返回 0。 */
uint8_t PanView_Ring_ReadByte(PanViewRingBuffer *buffer, uint8_t *output);

/* 返回缓冲区内尚未读取的字节数。 */
uint16_t PanView_Ring_GetUsed(const PanViewRingBuffer *buffer);

/* 初始化文本行累积器。 */
void PanView_Line_Init(PanViewLineAccumulator *line);

/*
 * 输入一个字节。
 * 拼出完整行时返回 1，并把 C 字符串写入 output；否则返回 0。
 */
uint8_t PanView_Line_Feed(PanViewLineAccumulator *line,
                          uint8_t byte,
                          char *output,
                          uint16_t output_capacity);

/* 解析一行 PV04 文本。成功返回 1，格式错误返回 0。 */
uint8_t PanView_PV04_Parse(const char *line, VisionResult *result);

#endif
```

### 2.2 `panview_t05.c`

```c
#include "panview_t05.h"

#include <stdio.h>
#include <string.h>

/* 把数组下标向前移动一格；到达末尾后回到 0。 */
static uint16_t next_index(uint16_t index)
{
    index++;
    if (index >= PANVIEW_RING_CAPACITY)
    {
        index = 0U;
    }
    return index;
}

void PanView_Ring_Init(PanViewRingBuffer *buffer)
{
    if (buffer == NULL)
    {
        return;
    }

    buffer->write_index = 0U;
    buffer->read_index = 0U;
}

uint16_t PanView_Ring_Write(PanViewRingBuffer *buffer,
                            const uint8_t *input,
                            uint16_t length)
{
    uint16_t written = 0U;
    uint16_t write_index;

    if ((buffer == NULL) || (input == NULL))
    {
        return 0U;
    }

    /* 先使用局部变量操作，复制完成后再公布新的写位置。 */
    write_index = buffer->write_index;

    while (written < length)
    {
        uint16_t following = next_index(write_index);

        /*
         * 下一写位置与读位置相同，说明缓冲区已满。
         * 本实现不覆盖旧数据，而是停止写入并返回实际写入数量。
         */
        if (following == buffer->read_index)
        {
            break;
        }

        buffer->data[write_index] = input[written];
        write_index = following;
        written++;
    }

    buffer->write_index = write_index;
    return written;
}

uint8_t PanView_Ring_ReadByte(PanViewRingBuffer *buffer, uint8_t *output)
{
    uint16_t read_index;

    if ((buffer == NULL) || (output == NULL))
    {
        return 0U;
    }

    read_index = buffer->read_index;

    /* 读写位置相同表示没有待读数据。 */
    if (read_index == buffer->write_index)
    {
        return 0U;
    }

    *output = buffer->data[read_index];
    buffer->read_index = next_index(read_index);
    return 1U;
}

uint16_t PanView_Ring_GetUsed(const PanViewRingBuffer *buffer)
{
    uint16_t write_index;
    uint16_t read_index;

    if (buffer == NULL)
    {
        return 0U;
    }

    write_index = buffer->write_index;
    read_index = buffer->read_index;

    if (write_index >= read_index)
    {
        return (uint16_t)(write_index - read_index);
    }

    return (uint16_t)(PANVIEW_RING_CAPACITY - read_index + write_index);
}

void PanView_Line_Init(PanViewLineAccumulator *line)
{
    if (line == NULL)
    {
        return;
    }

    line->size = 0U;
    line->discarding = 0U;
}

uint8_t PanView_Line_Feed(PanViewLineAccumulator *line,
                          uint8_t byte,
                          char *output,
                          uint16_t output_capacity)
{
    uint16_t i;

    if ((line == NULL) || (output == NULL) || (output_capacity == 0U))
    {
        return 0U;
    }

    /* PV04 使用 \r\n 结尾，\r 不属于正文，可以直接忽略。 */
    if (byte == '\r')
    {
        return 0U;
    }

    if (byte == '\n')
    {
        /* 当前行曾经溢出：清除丢弃状态，但不输出这条损坏的行。 */
        if (line->discarding != 0U)
        {
            line->size = 0U;
            line->discarding = 0U;
            return 0U;
        }

        /* 输出数组必须还能够容纳最后的 '\0'。 */
        if ((line->size + 1U) > output_capacity)
        {
            line->size = 0U;
            return 0U;
        }

        for (i = 0U; i < line->size; i++)
        {
            output[i] = line->data[i];
        }
        output[line->size] = '\0';

        /* 一行提交后清零，为下一行做准备。 */
        line->size = 0U;
        return 1U;
    }

    /* 当前损坏行尚未结束，继续忽略其中的所有字节。 */
    if (line->discarding != 0U)
    {
        return 0U;
    }

    if (line->size >= (PANVIEW_LINE_CAPACITY - 1U))
    {
        /* 防止数组越界，并丢弃到下一次换行。 */
        line->size = 0U;
        line->discarding = 1U;
        return 0U;
    }

    line->data[line->size] = (char)byte;
    line->size++;
    return 0U;
}

uint8_t PanView_PV04_Parse(const char *line, VisionResult *result)
{
    unsigned long timestamp;
    unsigned int target;
    unsigned int count;
    int x;
    int y;
    int width;
    int height;
    int center_x_integer;
    int center_x_fraction;
    int center_y_integer;
    int center_y_fraction;
    int fps_integer;
    int fps_fraction;
    char confidence_text[32];
    int fields;

    if ((line == NULL) || (result == NULL))
    {
        return 0U;
    }

    /* 所有 PV04 帧都有时间戳、目标状态和目标数量。 */
    fields = sscanf(line,
                    "PV04 t_ms=%lu target=%u count=%u",
                    &timestamp,
                    &target,
                    &count);

    if ((fields != 3) || (target > 1U))
    {
        return 0U;
    }

    /* 先清零，避免上一帧的坐标残留到无目标帧。 */
    memset(result, 0, sizeof(*result));

    result->source_timestamp_ms = (uint32_t)timestamp;
    result->target_count = (uint16_t)count;
    result->target_present = (uint8_t)target;

    /* 当前 K230 pipeline 使用 1920x1080，这两个字段不是文本字段。 */
    result->frame_width_px = 1920U;
    result->frame_height_px = 1080U;

    /* target=0 的帧到这里已经解析完成，没有坐标字段。 */
    if (target == 0U)
    {
        return 1U;
    }

    /*
     * STM32 nano scanf 通常没有启用 %f 浮点输入。
     * 因此把 1035.0 拆成整数部分和小数部分读取。
     */
    fields = sscanf(
        line,
        "PV04 t_ms=%lu target=%u count=%u x=%d y=%d w=%d h=%d "
        "cx=%d.%d cy=%d.%d confidence=%31s fps=%d.%d",
        &timestamp,
        &target,
        &count,
        &x,
        &y,
        &width,
        &height,
        &center_x_integer,
        &center_x_fraction,
        &center_y_integer,
        &center_y_fraction,
        confidence_text,
        &fps_integer,
        &fps_fraction);

    /* 有目标帧应当正好解析出 14 个字段。 */
    if (fields != 14)
    {
        return 0U;
    }

    result->target_x_px = (int16_t)x;
    result->target_y_px = (int16_t)y;
    result->target_width_px = (uint16_t)width;
    result->target_height_px = (uint16_t)height;

    /* 当前中心坐标的小数部分不参与运动控制，只保留整数像素。 */
    result->center_x_px = (float)center_x_integer;
    result->center_y_px = (float)center_y_integer;

    /* 这些字段已经成功读取，但当前任务不使用它们。 */
    (void)center_x_fraction;
    (void)center_y_fraction;
    (void)confidence_text;
    (void)fps_integer;
    (void)fps_fraction;

    return 1U;
}
```

```c
#ifndef PANVIEW_T06_H
#define PANVIEW_T06_H

#include <stddef.h>
#include <stdint.h>

#include "panview_t05.h"

    /* 俯仰轴速度，正负号表示方向，单位 step/s。 */

    uint32_t generated_tick_ms;

    uint8_t valid;

void PanView_Motion_CreateCommand(const VisionResult *vision,
```

### 2.4 `panview_t06.c`

```c
#include "panview_t06.h"

/* 把速度限制在 -800～+800 step/s。 */
static int32_t limit_speed(int32_t speed)
{
    if (speed > PANVIEW_MAX_SPEED_STEP_PER_S)
    {
        return PANVIEW_MAX_SPEED_STEP_PER_S;
    }

    if (speed < -PANVIEW_MAX_SPEED_STEP_PER_S)
    {
        return -PANVIEW_MAX_SPEED_STEP_PER_S;
    }

    return speed;
}

/* 把单轴像素误差转换成单轴目标速度。 */
static int32_t error_to_speed(int16_t error_px)
{
    /* 误差处于死区内时不运动，避免在中心附近抖动。 */
    if ((error_px <= PANVIEW_DEAD_ZONE_PX) &&
        (error_px >= -PANVIEW_DEAD_ZONE_PX))
    {
        return 0;
    }

    return limit_speed((int32_t)error_px * PANVIEW_GAIN_STEPS_PER_PIXEL);
}

/* 让 previous_speed 每次只向 target_speed 靠近 40 step/s。 */
static int32_t approach_speed(int32_t target_speed, int32_t previous_speed)
{
    int64_t difference = (int64_t)target_speed - previous_speed;

    if (difference > PANVIEW_SLEW_STEP_PER_PERIOD)
    {
        return previous_speed + PANVIEW_SLEW_STEP_PER_PERIOD;
    }

    if (difference < -PANVIEW_SLEW_STEP_PER_PERIOD)
    {
        return previous_speed - PANVIEW_SLEW_STEP_PER_PERIOD;
    }

    /* 剩余差值不足 40 时直接到达目标。 */
    return target_speed;
}

void PanView_Motion_CalculateError(const VisionResult *vision,
                                   int16_t *error_x_px,
                                   int16_t *error_y_px)
{
    int32_t frame_center_x;
    int32_t frame_center_y;

    if ((error_x_px == NULL) || (error_y_px == NULL))
    {
        return;
    }

    /* 默认停止：无目标或无输入时，误差输出必须为零。 */
    *error_x_px = 0;
    *error_y_px = 0;

    if ((vision == NULL) || (vision->target_present == 0U))
    {
        return;
    }

    frame_center_x = (int32_t)vision->frame_width_px / 2;
    frame_center_y = (int32_t)vision->frame_height_px / 2;

    /*
     * 正 X：目标在画面中心右侧。
     * 负 X：目标在画面中心左侧。
     * 正 Y：目标在画面中心下方。
     * 负 Y：目标在画面中心上方。
     */
    *error_x_px = (int16_t)((int32_t)vision->center_x_px - frame_center_x);
    *error_y_px = (int16_t)((int32_t)vision->center_y_px - frame_center_y);
}

void PanView_Motion_CreateCommand(const VisionResult *vision,
                                  uint32_t generated_tick_ms,
                                  MotionCommand *command)
{
    int16_t error_x_px;
    int16_t error_y_px;

    if (command == NULL)
    {
        return;
    }

    /* 先生成安全默认值，任何提前返回都会得到停止命令。 */
    command->pan_speed_steps_per_second = 0;
    command->pitch_speed_steps_per_second = 0;
    command->generated_tick_ms = generated_tick_ms;
    command->valid = 0U;

    if ((vision == NULL) || (vision->target_present == 0U))
    {
        return;
    }

    PanView_Motion_CalculateError(vision, &error_x_px, &error_y_px);

    command->pan_speed_steps_per_second = error_to_speed(error_x_px);
    command->pitch_speed_steps_per_second = error_to_speed(error_y_px);
    command->valid = 1U;
}

void PanView_Motion_ApplySlewRate(const MotionCommand *target_command,
                                  const MotionCommand *previous_command,
                                  MotionCommand *limited_command)
{
    int32_t previous_pan = 0;
    int32_t previous_pitch = 0;

    if ((target_command == NULL) || (limited_command == NULL))
    {
        return;
    }

    /* 目标消失属于停止条件，立即清零，不继续缓慢运行。 */
    if (target_command->valid == 0U)
    {
        limited_command->pan_speed_steps_per_second = 0;
        limited_command->pitch_speed_steps_per_second = 0;
        limited_command->generated_tick_ms = target_command->generated_tick_ms;
        limited_command->valid = 0U;
        return;
    }

    if (previous_command != NULL)
    {
        previous_pan = previous_command->pan_speed_steps_per_second;
        previous_pitch = previous_command->pitch_speed_steps_per_second;
    }

    limited_command->pan_speed_steps_per_second = approach_speed(
        target_command->pan_speed_steps_per_second,
        previous_pan);

    limited_command->pitch_speed_steps_per_second = approach_speed(
        target_command->pitch_speed_steps_per_second,
        previous_pitch);

    limited_command->generated_tick_ms = target_command->generated_tick_ms;
    limited_command->valid = 1U;
}

uint8_t PanView_Motion_UpdateLock(uint8_t target_present,
                                  int16_t error_x_px,
                                  int16_t error_y_px,
                                  uint8_t previous_locked)
{
    if (target_present == 0U)
    {
        return 0U;
    }

    if (previous_locked != 0U)
    {
        /*
         * 已经锁定时使用较大的 60 px 退出阈值。
         * 这样误差在 40～60 px 之间波动时不会反复启停。
         */
        if ((error_x_px > PANVIEW_LOCK_EXIT_PX) ||
            (error_x_px < -PANVIEW_LOCK_EXIT_PX) ||
            (error_y_px > PANVIEW_LOCK_EXIT_PX) ||
            (error_y_px < -PANVIEW_LOCK_EXIT_PX))
        {
            return 0U;
        }

        return 1U;
    }

    /* 未锁定时，必须双轴同时进入 ±40 px 才建立锁定。 */
    if ((error_x_px <= PANVIEW_LOCK_ENTER_PX) &&
        (error_x_px >= -PANVIEW_LOCK_ENTER_PX) &&
        (error_y_px <= PANVIEW_LOCK_ENTER_PX) &&
        (error_y_px >= -PANVIEW_LOCK_ENTER_PX))
    {
        return 1U;
    }

    return 0U;
}
```

## 3. 代码拆解讲解

### 3.1 T05 使用的变量

#### `PanViewRingBuffer` 成员

| 变量 | 类型 | 作用 |
|---|---|---|
| `data[]` | `uint8_t[1024]` | 保存 USART 收到但尚未处理的原始字节 |
| `write_index` | `volatile uint16_t` | 指向下一次写入位置，由接收侧推进 |
| `read_index` | `volatile uint16_t` | 指向下一次读取位置，由解析侧推进 |

`volatile` 表示这个值可能被另一个执行环境改变，编译器每次都应重新读取。但 `volatile` 不等于线程锁，只适用于当前“单写入者、单读取者”的简单模型。

#### `PanViewLineAccumulator` 成员

| 变量 | 作用 |
|---|---|
| `data[]` | 保存尚未遇到 `\n` 的当前文本行 |
| `size` | 当前已保存字符数量，也是下一字符的写入位置 |
| `discarding` | 当前行过长时置 1，避免把后半截误认为新帧 |

#### `VisionResult` 主要成员

| 变量 | 单位 | 作用 |
|---|---|---|
| `source_timestamp_ms` | ms | K230 产生视觉帧的时间 |
| `target_count` | 个 | 当前检测目标数量 |
| `target_present` | 布尔值 | 0 无目标，1 有可用目标 |
| `frame_width_px` / `frame_height_px` | px | 图像尺寸，当前为 1920x1080 |
| `target_x_px` / `target_y_px` | px | 目标框左上角 |
| `target_width_px` / `target_height_px` | px | 目标框大小 |
| `center_x_px` / `center_y_px` | px | 目标中心，T06真正使用的数据 |

#### T05 局部变量

- `written`：本次成功写入环形缓冲区的字节数。
- `write_index`、`read_index`：局部索引，完成数据操作后再发布到结构体。
- `byte`：从环形缓冲区取出的单个字节。
- `fields`：`sscanf()` 实际成功匹配的字段数量。
- `timestamp`、`target`、`count`：公共字段的临时接收变量。
- `center_x_integer` 等：为绕开 nano `scanf` 浮点输入限制而设置的整数临时变量。
- `confidence_text`：用字符串接收 `confidence`，兼容数值或 `unavailable`。

### 3.2 T06 使用的变量

#### `MotionCommand` 成员

| 变量 | 单位 | 作用 |
|---|---|---|
| `pan_speed_steps_per_second` | step/s | 水平轴速度 |
| `pitch_speed_steps_per_second` | step/s | 俯仰轴速度 |
| `generated_tick_ms` | ms | STM32 生成命令的时间 |
| `valid` | 布尔值 | 0 表示不可执行，1 表示来自有效视觉目标 |

#### T06 控制参数

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `PANVIEW_DEAD_ZONE_PX` | 40 px | 中心附近不产生目标速度 |
| `PANVIEW_GAIN_STEPS_PER_PIXEL` | 2 | 每 1 px 误差对应 2 step/s |
| `PANVIEW_MAX_SPEED_STEP_PER_S` | 800 step/s | 防止速度无限增大 |
| `PANVIEW_SLEW_STEP_PER_PERIOD` | 40 step/s | 每个 10 ms 周期允许的最大速度变化 |
| `PANVIEW_LOCK_ENTER_PX` | 40 px | 双轴进入该范围后锁定 |
| `PANVIEW_LOCK_EXIT_PX` | 60 px | 锁定后任意轴超过该范围才退出 |

#### MotionTask 中需要长期保存的变量

- `latest_vision`：最近一份视觉结果，新结果到来时覆盖旧结果。
- `target_command`：根据当前误差直接算出的期望速度。
- `shadow_command`：经过斜率限制后的实际影子输出，也是下一周期的历史速度。
- `target_locked`：上一周期锁定状态，必须跨周期保存。
- `error_x_px`、`error_y_px`：当前目标相对画面中心的误差。

### 3.3 对外公开接口函数

#### T05 接口

| 函数 | 调用方 | 入参 | 返回值 |
|---|---|---|---|
| `PanView_Ring_Init()` | 系统初始化 | 缓冲区指针 | 无 |
| `PanView_Ring_Write()` | UART DMA/空闲回调 | 缓冲区、字节数组、长度 | 实际写入字节数 |
| `PanView_Ring_ReadByte()` | VisionRxTask | 缓冲区、输出字节指针 | 1 成功，0 无数据/参数错误 |
| `PanView_Ring_GetUsed()` | 调试或遥测 | 缓冲区指针 | 当前待读字节数 |
| `PanView_Line_Init()` | VisionRxTask 初始化 | 行累积器指针 | 无 |
| `PanView_Line_Feed()` | VisionRxTask | 累积器、单字节、输出数组 | 1 得到完整行，0 尚未完成 |
| `PanView_PV04_Parse()` | VisionRxTask | 完整文本行、结果指针 | 1 解析成功，0 格式错误 |

#### T06 接口

| 函数 | 调用方 | 入参 | 输出/返回值 |
|---|---|---|---|
| `PanView_Motion_CalculateError()` | MotionTask | `VisionResult` | 通过指针输出 X/Y 误差 |
| `PanView_Motion_CreateCommand()` | MotionTask | 视觉结果、当前时间 | 输出未经斜率限制的目标命令 |
| `PanView_Motion_ApplySlewRate()` | MotionTask | 目标命令、上一命令 | 输出平滑后的影子命令 |
| `PanView_Motion_UpdateLock()` | MotionTask | 有无目标、误差、上一锁定状态 | 返回新的锁定状态 |

### 3.4 内部私有函数

#### `next_index()`

只负责计算环形缓冲区的下一个数组位置。集中处理回绕逻辑，可以避免每个读写函数重复写边界判断。

#### `limit_speed()`

把比例计算结果限制在 `-800～+800 step/s`，避免大误差产生过大的速度。

#### `error_to_speed()`

完成单轴转换：

```text
误差在 ±40 px 内 -> 速度 0
否则 -> 误差 × 2
最后 -> 限制到 ±800 step/s
```

#### `approach_speed()`

让当前速度逐步靠近目标速度。每次最多变化 `40 step/s`：

```text
上一速度 0，目标速度 800
第1周期 40
第2周期 80
第3周期 120
...
```

### 3.5 T05 完整执行流程

1. 系统启动时初始化环形缓冲区和文本行累积器。
2. USART2 DMA/空闲回调收到一批字节。
3. 回调调用 `PanView_Ring_Write()`，快速复制字节后立即返回。
4. VisionRxTask 从环形缓冲区逐字节读取。
5. 每个字节交给 `PanView_Line_Feed()`。
6. 遇到 `\r` 时忽略，遇到 `\n` 时提交完整字符串。
7. 调用 `PanView_PV04_Parse()`。
8. `target=0` 时只填写公共字段，所有坐标保持零。
9. `target=1` 时检查并解析完整 14 个字段。
10. 解析成功后得到新的 `VisionResult`。
11. 原工程把结果发布到容量为 1 的消息队列，只保留最新视觉结果。

### 3.6 T06 完整执行流程

原工程的 MotionTask 每 10 ms 执行：

1. 尝试读取最新的 `VisionResult`；没有新结果时继续保留上一份。
2. 计算 `error_x_px` 和 `error_y_px`。
3. 根据上一锁定状态更新 `target_locked`。
4. 根据死区、比例系数和最大速度生成 `target_command`。
5. 如果已经锁定，把目标速度设为零。
6. 使用上一周期的 `shadow_command` 做斜率限制。
7. 保存新的 `shadow_command`，供下一周期继续使用。
8. 低频输出 USART1 日志用于观察。
9. 不向 StepperTask 发布命令，也不驱动电机。

### 3.7 嵌入式开发坑点和注意事项

#### 一次 UART 回调不等于一帧

DMA 数据可能拆帧，也可能一次包含多帧。必须按照协议结束符 `\r\n` 组帧，而不是按照 DMA 回调次数组帧。

#### 环形缓冲区要区分空和满

本实现保留一个空槽：

```text
read_index == write_index：空
next(write_index) == read_index：满
```

因此 1024 字节数组最多保存 1023 字节，这是标准且容易理解的做法。

#### 中断里不要解析文本

`sscanf()` 很慢、占栈较大。中断只复制字节，解析工作放到任务中，避免阻塞其他中断。

#### `volatile` 不是互斥锁

当前环形缓冲区只适用于单生产者和单消费者。如果以后多个任务同时写入或读取，需要临界区、互斥量或专门的并发队列。

#### 必须处理过长文本行

如果一行超过数组容量，不能继续写数组，也不能立即把后半截当新帧。正确方法是丢弃到下一个 `\n`，重新同步协议边界。

#### `sscanf()` 必须检查返回值

不能只看字符串开头是 `PV04` 就认为成功。有目标帧必须匹配 14 项，否则结构体中可能混入未初始化变量。

#### nano C 库可能不支持 `%f`

STM32 常用的 nano `scanf` 默认可能不解析浮点数。本项目通过 `%d.%d` 分别读取整数和小数部分，避免为了输入浮点数显著增加固件体积。

#### 无目标帧必须清空旧坐标

解析前使用 `memset()` 清零。如果只修改 `target_present`，旧目标坐标可能残留，并被后续模块误用。

#### `snprintf()` 和 `sscanf()` 会消耗较多任务栈

T05 实机曾发现 VisionRxTask 的 512 Words 栈不足。通过 FreeRTOS：

```c
uxTaskGetStackHighWaterMark(task_handle)
```

以及：

```c
configCHECK_FOR_STACK_OVERFLOW = 2
vApplicationStackOverflowHook()
```

确认溢出任务是 `VisionRxTask`。最终把该任务调整为 1024 Words，实测历史最低剩余约 488 Words。

#### 最新值语义不等于累计队列

视觉控制只关心最新目标。旧的十帧即使依次处理完，也已经不能代表目标当前位置。因此原工程使用容量为 1 的视觉结果队列，新结果覆盖旧结果。

#### 斜率限制需要保存上一周期状态

如果 `previous_command` 每次都重新清零，输出永远只能到 `40 step/s`。它必须是任务循环外的长期变量。

#### 锁定滞回必须有两个阈值

只使用一个 40 px 阈值，会在 39/41 px 附近反复启停。进入使用 40 px、退出使用 60 px，可以吸收少量视觉抖动。

#### `valid=0` 与“有效命令速度为0”含义不同

```text
valid=0：当前没有有效视觉目标
valid=1 且速度=0：有目标，但位于死区或已经锁定
```

#### 当前 T06 不能做真实软件位置限位

位置限位必须知道真实或可信的累计步数，并且需要确定零点。影子命令阶段尚未驱动电机，因此不能假装拥有可靠位置。

## 4. main 简易测试 demo

下面的示例不使用 HAL 和 FreeRTOS。它模拟 UART 分成三次收到一条 PV04 帧，然后执行 T05 和 T06。

```c
#include <stdio.h>
#include <string.h>

#include "panview_t05.h"
#include "panview_t06.h"

int main(void)
{
    PanViewRingBuffer rx_ring;
    PanViewLineAccumulator line_accumulator;
    VisionResult latest_vision;

    MotionCommand target_command = {0};
    MotionCommand shadow_command = {0};

    char complete_line[PANVIEW_LINE_CAPACITY];
    uint8_t byte;
    int16_t error_x_px;
    int16_t error_y_px;
    uint8_t target_locked = 0U;

    /* 模拟同一条串口帧被 DMA 分成三次收到。 */
    const char *chunk1 = "PV04 t_ms=18278 target=1 co";
    const char *chunk2 = "unt=1 x=771 y=0 w=528 h=786 cx=1035.0";
    const char *chunk3 = " cy=393.0 confidence=0.0000 fps=0.00\r\n";

    PanView_Ring_Init(&rx_ring);
    PanView_Line_Init(&line_accumulator);
    memset(&latest_vision, 0, sizeof(latest_vision));

    /* 真实工程中，这三次写入发生在 UART DMA/空闲回调中。 */
    PanView_Ring_Write(&rx_ring,
                       (const uint8_t *)chunk1,
                       (uint16_t)strlen(chunk1));
    PanView_Ring_Write(&rx_ring,
                       (const uint8_t *)chunk2,
                       (uint16_t)strlen(chunk2));
    PanView_Ring_Write(&rx_ring,
                       (const uint8_t *)chunk3,
                       (uint16_t)strlen(chunk3));

    /* 真实工程中，下面的循环位于 VisionRxTask。 */
    while (PanView_Ring_ReadByte(&rx_ring, &byte) != 0U)
    {
        if (PanView_Line_Feed(&line_accumulator,
                              byte,
                              complete_line,
                              sizeof(complete_line)) != 0U)
        {
            if (PanView_PV04_Parse(complete_line, &latest_vision) != 0U)
            {
                printf("T05: target=%u center=(%.0f, %.0f)\n",
                       latest_vision.target_present,
                       latest_vision.center_x_px,
                       latest_vision.center_y_px);
            }
            else
            {
                printf("T05: PV04 parse failed\n");
                return 1;
            }
        }
    }

    /* 真实工程中，下面的计算由 MotionTask 每 10 ms 执行一次。 */
    PanView_Motion_CalculateError(&latest_vision,
                                  &error_x_px,
                                  &error_y_px);

    target_locked = PanView_Motion_UpdateLock(
        latest_vision.target_present,
        error_x_px,
        error_y_px,
        target_locked);

    PanView_Motion_CreateCommand(&latest_vision,
                                 1000U,
                                 &target_command);

    /* 锁定后目标速度为零，但命令仍然是有效目标产生的。 */
    if (target_locked != 0U)
    {
        target_command.pan_speed_steps_per_second = 0;
        target_command.pitch_speed_steps_per_second = 0;
    }

    /* 第一次运行时，上一影子速度为0，因此最多只增加40 step/s。 */
    PanView_Motion_ApplySlewRate(&target_command,
                                 &shadow_command,
                                 &shadow_command);

    printf("T06: locked=%u err_x=%d err_y=%d target_pan=%ld pan=%ld "
           "target_pitch=%ld pitch=%ld valid=%u\n",
           target_locked,
           error_x_px,
           error_y_px,
           (long)target_command.pan_speed_steps_per_second,
           (long)shadow_command.pan_speed_steps_per_second,
           (long)target_command.pitch_speed_steps_per_second,
           (long)shadow_command.pitch_speed_steps_per_second,
           shadow_command.valid);

    return 0;
}
```

预期结果近似为：

```text
T05: target=1 center=(1035, 393)
T06: locked=0 err_x=75 err_y=-147 target_pan=150 pan=40 target_pitch=-294 pitch=-40 valid=1
```

为什么第一次影子速度只有 `40/-40`：

```text
水平目标速度 = 75 × 2 = 150 step/s
俯仰目标速度 = -147 × 2 = -294 step/s

上一周期速度 = 0
每周期最多变化 = 40 step/s

所以第一次输出：pan=40，pitch=-40
```

如果在循环中连续调用，速度会逐步接近目标：

```text
第1周期：pan=40
第2周期：pan=80
第3周期：pan=120
第4周期：pan=150
```

这就是 T05 和 T06 最核心的调用关系：

```text
原始字节
-> 完整文本行
-> VisionResult
-> 像素误差
-> 目标速度
-> 平滑影子速度
```
