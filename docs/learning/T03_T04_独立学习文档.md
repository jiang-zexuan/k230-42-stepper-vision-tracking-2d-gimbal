# PanView T03、T04 独立学习文档

> 本文面向初学者。代码是从 STM32 工程中抽出的学习版，重点是理解“数据如何定义、字节如何暂存”。它不包含电机、PID、UI、安全停机等无关内容。

## 1. 任务需求说明

### 1.1 T03：统一消息和状态快照

**目标**：让不同 RTOS 任务使用统一的数据格式通信，避免每个任务自己发明一套变量。

**输入**：K230 视觉结果、按键请求、控制计算结果。

**输出**：`VisionResult`、`MotionCommand`、`InputEvent`、`IndicatorEvent` 和 `PanViewStateSnapshot`。

**底层依赖**：C 基础类型、STM32 本地毫秒节拍（实际工程中来自 HAL/FreeRTOS）。T03 只定义数据，不创建队列，也不解析串口。

当前 K230 文本帧示例：

```text
PV04 t_ms=18278 target=1 count=1 x=771 y=0 w=528 h=786 cx=1035.0 cy=393.0 confidence=0.0000 fps=0.00\r\n
```

无目标帧示例：

```text
PV04 t_ms=17950 target=0 count=0\r\n
```

T03 的 `VisionResult` 是解析后的结果容器；真正的文本解析属于后续任务。

### 1.2 T04：串口字节接收和标准环形缓冲区

**目标**：把 USART2 DMA 回调收到的一小段字节连续保存起来，供接收任务稍后读取，避免回调中直接做复杂解析。

**输入**：UART/DMA 收到的字节块。

**输出**：按原顺序读出的字节流，以及写入数量、读取数量、当前占用量等信息。

**底层依赖**：STM32 USART2、DMA、HAL 回调、FreeRTOS 任务通知。学习版用普通函数模拟这些硬件部分。

真实工程信息：USART2 使用 115200、8N1；DMA 临时块收到后写入 1024 字节环形缓冲区。环形缓冲区实际最多保存 1023 字节，因为要留一个空位置区分“空”和“满”。

### 2.2 `panview_ring_buffer.h`

```c
#ifndef PANVIEW_RING_BUFFER_H
#define PANVIEW_RING_BUFFER_H

#include <stdint.h>

/* 数组大小是 1024，但最多存 1023 字节，保留一个空位判断满状态。 */
#define PANVIEW_RING_BUFFER_CAPACITY 1024U

typedef struct
{
    uint8_t data[PANVIEW_RING_BUFFER_CAPACITY];
    volatile uint16_t write_index; /* 写入位置，由接收侧推进。 */
    volatile uint16_t read_index;  /* 读取位置，由任务侧推进。 */
} PanViewRingBuffer;

void PanView_RingBuffer_Init(PanViewRingBuffer *buffer);
uint16_t PanView_RingBuffer_Write(PanViewRingBuffer *buffer,
                                  const uint8_t *data, uint16_t length);
uint16_t PanView_RingBuffer_Read(PanViewRingBuffer *buffer,
                                 uint8_t *output, uint16_t output_size);
uint16_t PanView_RingBuffer_GetUsed(const PanViewRingBuffer *buffer);

#endif
```

### 2.3 `panview_ring_buffer.c`

```c
#include "panview_ring_buffer.h"

/* 索引走到数组末尾后回到 0。 */
static uint16_t next_index(uint16_t index)
{
    index++;
    return (index >= PANVIEW_RING_BUFFER_CAPACITY) ? 0U : index;
}

void PanView_RingBuffer_Init(PanViewRingBuffer *buffer)
{
    if (buffer == 0) return;
    buffer->write_index = 0U;
    buffer->read_index = 0U;
}

uint16_t PanView_RingBuffer_Write(PanViewRingBuffer *buffer,
                                  const uint8_t *data, uint16_t length)
{
    uint16_t written = 0U;
    uint16_t index;
    if ((buffer == 0) || (data == 0)) return 0U;
    index = buffer->write_index;
    while (written < length)
    {
        uint16_t next = next_index(index);
        /* 下一格等于读位置，表示没有空间，不能覆盖旧数据。 */
        if (next == buffer->read_index) break;
        buffer->data[index] = data[written++];
        index = next;
    }
    /* 最后再更新写位置，读侧不会看到尚未复制完的数据。 */
    buffer->write_index = index;
    return written;
}

uint16_t PanView_RingBuffer_Read(PanViewRingBuffer *buffer,
                                 uint8_t *output, uint16_t output_size)
{
    uint16_t count = 0U;
    uint16_t index;
    if ((buffer == 0) || (output == 0)) return 0U;
    index = buffer->read_index;
    while ((count < output_size) && (index != buffer->write_index))
    {
        output[count++] = buffer->data[index];
        index = next_index(index);
    }
    buffer->read_index = index;
    return count;
}

uint16_t PanView_RingBuffer_GetUsed(const PanViewRingBuffer *buffer)
{
    uint16_t w, r;
    if (buffer == 0) return 0U;
    w = buffer->write_index;
    r = buffer->read_index;
    return (w >= r) ? (uint16_t)(w - r)
                    : (uint16_t)(PANVIEW_RING_BUFFER_CAPACITY - r + w);
}
```

### 2.4 简化串口接收接口

真实工程中，DMA 回调调用“写入环形缓冲区”，接收任务调用“读取环形缓冲区”。学习版不依赖 HAL：

```c
/* panview_uart_learning.h */
#ifndef PANVIEW_UART_LEARNING_H
#define PANVIEW_UART_LEARNING_H
#include "panview_ring_buffer.h"
void PanView_UartLearning_Init(void);
uint16_t PanView_UartLearning_OnDmaBytes(const uint8_t *data, uint16_t length);
uint16_t PanView_UartLearning_Read(uint8_t *output, uint16_t size);
#endif
```

```c
/* panview_uart_learning.c */
#include "panview_uart_learning.h"
static PanViewRingBuffer g_uart_buffer;
void PanView_UartLearning_Init(void) { PanView_RingBuffer_Init(&g_uart_buffer); }
uint16_t PanView_UartLearning_OnDmaBytes(const uint8_t *data, uint16_t length)
{
    return PanView_RingBuffer_Write(&g_uart_buffer, data, length);
}
uint16_t PanView_UartLearning_Read(uint8_t *output, uint16_t size)
{
    return PanView_RingBuffer_Read(&g_uart_buffer, output, size);
}
```

## 3. 代码拆解讲解

### 3.1 变量和结构体成员

`VisionResult` 保存一帧视觉结果；`MotionCommand` 保存双轴速度；`InputEvent` 和 `IndicatorEvent` 保存一次事件；`PanViewStateSnapshot` 保存 UI/遥测需要读取的只读状态。

环形缓冲区只有三个核心成员：`data` 是字节数组，`write_index` 指向下一次写入位置，`read_index` 指向下一次读取位置。`next_index`、`written`、`count`、`index` 都是函数内部临时变量。

### 3.2 对外接口

- `PanView_RingBuffer_Init`：调用方在启动时调用；清空读写位置；无返回值。
- `PanView_RingBuffer_Write`：DMA 回调或接收函数调用；返回实际写入字节数，满时可能小于请求数。
- `PanView_RingBuffer_Read`：接收任务调用；返回实际读取字节数，没数据时为 0。
- `PanView_RingBuffer_GetUsed`：调试或遥测调用；返回当前待读字节数。
- `PanView_UartLearning_OnDmaBytes`：模拟“DMA 收到一块数据”。
- `PanView_UartLearning_Read`：模拟“任务读取数据”。

### 3.3 私有函数

`next_index` 只负责环形索引回绕，不对外公开，避免其他模块直接修改环形缓冲区内部规则。

### 3.4 完整执行流程

1. 初始化环形缓冲区。
2. USART2 DMA 收到字节块。
3. 接收回调把字节块写入环形缓冲区，并通知接收任务。
4. 接收任务读取字节；T04 到这里结束。
5. 后续 T05 再按 `\r\n` 组完整文本行并解析为 `VisionResult`。
6. 其他任务读取统一消息或状态快照。

### 3.5 嵌入式坑点

- 环形缓冲区容量 1024 不等于可用 1024，实际可用 1023。
- 写入返回值必须检查；小于请求长度说明发生丢弃。
- DMA 回调中只做快速搬运，不要在中断/回调里做字符串解析。
- `volatile` 只能帮助编译器重新读取索引，不能自动解决所有并发问题；复杂多生产者场景需要临界区或锁。
- `uint16_t` 索引适合本容量；若容量扩大，需重新检查整数范围。
- PV04 的 `confidence` 和 `fps` 当前日志为 0，不能擅自当作可靠控制量。

## 4. main 简易测试 demo

下面示例模拟 K230 发来一行 PV04 文本。它只验证“收到字节并按原样读出”，不做协议解析。

```c
#include <stdio.h>
#include <string.h>
#include "panview_uart_learning.h"

int main(void)
{
    const char frame[] = "PV04 t_ms=17950 target=0 count=0\r\n";
    uint8_t output[128];
    uint16_t received;

    PanView_UartLearning_Init();
    PanView_UartLearning_OnDmaBytes((const uint8_t *)frame,
                                    (uint16_t)strlen(frame));

    received = PanView_UartLearning_Read(output, sizeof(output) - 1U);
    output[received] = '\0';

    printf("收到 %u 字节：%s", received, output);
    return 0;
}
```

PC 编译示例：

```text
gcc panview_ring_buffer.c panview_uart_learning.c main.c -o t03_t04_demo
```

预期输出：

```text
收到 36 字节：PV04 t_ms=17950 target=0 count=0
```

这份 demo 的验收重点是：字节数量正确、内容顺序不变、末尾 `\r\n` 也被保留。解析字段和生成 `VisionResult` 留到 T05。
